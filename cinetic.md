# cinetic

**cinetic** ([github.com/Leonxlnx/cinetic](https://github.com/Leonxlnx/cinetic)) es una skill open source (MIT) para que tu agente de código (Claude Code, Codex, Cursor...) dirija películas de lanzamiento y vídeos de actualización escritos en código: construye con Remotion (React) por defecto o con [[HyperFrames]] (HTML y GSAP). La crea Camille Roux.

## Qué hace

- De un brief de un párrafo genera la película completa: estructura, tipos de plano, tipografía, tiempos, transiciones y coreografía.
- Sonido guiado por la música: cada film se corta sobre una pista instrumental con licencia (hecha por humanos) elegida por mood, tempo y duración, con efectos de una librería real; no genera música con IA ni mete nada con copyright.
- Las plantillas son el suelo, nunca la película: todo texto en pantalla sale de un archivo de contenido cuyos placeholders hacen fallar el lint hasta que pones las palabras del producto.
- La v1.5 (noviembre 2026) añade 34 escenas preconstruidas, según su anuncio.

## Uso

```
npx skills add Leonxlnx/cinetic
```

Luego pides al agente algo como «haz una película de lanzamiento de 25 segundos con música para nuestra herramienta» y él monta el proyecto solo.

## Estado

Unas 1.100 estrellas (noviembre 2026); creado en septiembre de 2026. Los films de ejemplo del repo están hechos por un agente con cinetic 1.5 a partir de un párrafo, según el autor.
