# Vibe Kanban

**Vibe Kanban** ([vibekanban.com](https://vibekanban.com), repo `BloopAI/vibe-kanban`, Apache-2.0, 27.8k ⭐) es un **tablero kanban para orquestar agentes de código en paralelo**: planificas en issues, cada workspace da al agente branch + terminal + dev server, revisas diffs con comentarios inline, previsualizas en navegador integrado y cambias entre **10+ agentes** (Claude Code, Codex, Gemini CLI, Copilot, Amp, Cursor, OpenCode…). `npx vibe-kanban`. Hilo de [@Saboo_Shubham_](https://x.com/Saboo_Shubham_) (158k views).

## Aviso importante: en sunset

Bloop (la empresa) cerró en abril 2026: el proyecto sigue como **open source mantenido por la comunidad**. Si lo adoptas hoy:

- Alternativa viva: **vibe-kanban-indie** (fork self-hosted para un solo dev: sin cloud ni auth, con TUI y orquestación por Telegram)
- Alternativa minimalista: **claude-kanban** (MIT, dashboard que monitoriza sesiones Claude/Codex por SSH en varias máquinas)

## El loop

Describe el trabajo → el agente ejecuta en su workspace → revisas el diff → merge con PR generada por IA. Planificar y revisar más rápido es todo el juego cuando los agentes escriben el código.
