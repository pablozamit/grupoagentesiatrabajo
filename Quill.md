# Quill

**Quill** es una app open source para macOS que graba audio de reuniones y lo transcribe automáticamente al detener la grabación. Alternativa gratuita y privada a Granola.

## Características

- **Grabación con un clic**: pulsa iniciar, pulsa parar → transcripción completa
- **Privado**: todo el procesamiento es local, sin servidores externos
- **Transcripción automática**: usa el modelo NVIDIA Parakeet
- **Archivos de audio conservados**: puedes re-escuchar la conversación original
- **Open source**: [github.com/digimata/quill](https://github.com/digimata/quill)
- **Carpeta por defecto**: todas las transcripciones se guardan automáticamente

## Limitaciones actuales

- Modelo NVIDIA Parakeet optimizado para inglés; otras lenguas pueden tener peor precisión
- No captura audio del sistema (solo micrófono)
