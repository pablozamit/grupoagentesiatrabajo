# OpenPencil

**OpenPencil** es un **editor de diseño open source (MIT)** que abre archivos nativos de Figma (`.fig`) y los suyos propios (`.pen`), con IA integrada y totalmente programable: CLI headless, servidor MCP e integraciones con Claude Code, Codex y Gemini CLI. 8.9k ⭐ (oct 2026).

## Qué es

- **Abre y escribe `.fig` y `.pen`**: lee y escribe archivos nativos de Figma y permite copiar/pegar nodos entre apps
- **IA que construye diseños**: describes lo que quieres en el chat y más de 100 herramientas crean y modifican nodos; conecta OpenRouter, Anthropic, OpenAI, Google AI, DeepSeek, Z.ai o MiniMax
- **Programable de verdad**: CLI headless (inspecciona el árbol de nodos, busca, extrae tokens sin abrir el editor), queries XPath, API compatible con plugins de Figma, servidor MCP y agentes de escritorio para Claude Code, Codex y Gemini CLI
- **Diseño de verdad**: componentes y variantes, auto layout y CSS Grid (Yoga WASM), lint de naming/layout/accesibilidad, vectorización de imágenes (Recraft o fal.ai), export a JSX/Tailwind y design tokens
- **Colaboración P2P** por WebRTC (cursores, presencia, modo follow, llamadas de voz): sin servidor y sin cuenta
- **App ligera**: ~15 MB con Tauri v2 para macOS, Windows y Linux; también funciona como PWA en el navegador

## v0.15.0 (sep 2026)

Según el anuncio oficial: variantes de componentes y librerías publicadas, interfaz rediseñada, guías y snapping, y un chat de IA que por fin funciona como espacio de trabajo.
