# ADE Call

ADE Call es una herramienta autoalojada para hablar por voz desde el navegador con agentes de [[Orca]] o [[T3 Code]]. Usa OpenAI Realtime o Gemini Live experimental y consume API; requiere Node 24 o posterior, y el proyecto solo declara Linux probado. El código usa licencia MIT.
