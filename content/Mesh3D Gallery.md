# Mesh3D Gallery

[Mesh3D Gallery](https://mesh3d.gallery/) es una **galería curada de sitios web con gráficos 3D**. Cada entrada muestra la tecnología que usa (Three.js, GSAP, WebGL, etc.) y sirve como inspiración para proyectos propios.

## Para qué sirve

- Ver ejemplos reales de páginas con 3D aplicado
- Descubrir qué herramientas y librerías usa cada sitio
- Inspirarse para tus propios proyectos web con 3D
