# MiMo Code

Herramienta gratuita de Xiaomi para vibe-coding. Incluye un modelo gratuito (MiMo Auto) sin necesidad de API keys, y permite conectar LLMs externos.

## Características clave

- **Memoria persistente** entre sesiones
- **Sub-agentes** que se crean y trabajan en paralelo automáticamente
- `/dream` — guarda conocimiento útil de la sesión en la memoria a largo plazo del proyecto
- `/distill` — convierte acciones repetidas en skills reutilizables
- `/goal` — usa un modelo verificador dedicado para determinar si la tarea está realmente completa

## Instalación

**Mac / Linux:**
```bash
curl -fsSL https://mimo.xiaomi.com/install | bash
```

**Windows:**
```bash
npm install -g @mimo-ai/cli
```

**Lanzar:**
```bash
mimo
```

100 % open source.
