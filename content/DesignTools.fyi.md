# DesignTools.fyi

[DesignTools.fyi](https://designtools.fyi/) es un **directorio curado de herramientas de diseño** que cataloga alrededor de 85 herramientas y las organiza por perfil de usuario, no solo por categoría técnica.

## Qué es

- Catálogo curado de **~85 herramientas** de diseño
- Cada herramienta tiene **puntuación, descripción, categorías y enlace**
- Se actualiza con frecuencia: añade herramientas nuevas y reordena según uso y novedades
- Incluye también **editorial / noticias** sobre el mundo de las herramientas de diseño con IA

## Organización por perfiles

En lugar de listar las herramientas solo por categoría (UI, tipografía, animación…), las agrupa según el **perfil del usuario**:

| Perfil | Para quién |
|--------|-----------|
| **All Rounder** | Visión equilibrada de todas las capacidades |
| **Art Director** | Exploración visual y dirección creativa |
| **Craft Specialist** | Ejecución pixel-perfect e interacción |
| **Design Engineer** | Implementación y puente entre diseño y código |
| **Design Ops** | Sistemas, escalabilidad y colaboración con desarrollo |
| **Non Designer** | Velocidad y facilidad de uso sobre control fino |

Cada perfil muestra su top de herramientas con un porcentaje de afinidad, así puedes ver **qué se ajusta mejor a tu rol**.

## Para qué sirve

Cuando quieres saber qué herramienta usar para una tarea de diseño y no quieres perder tiempo probando todo:

- Ver el **ranking curado** de una categoría concreta
- Filtrar por **perfil** (diseñador, desarrollador, no-diseñador, etc.)
- Consultar **editorial / noticias** para mantenerte al día de las novedades del sector
- Encontrar alternativas a la herramienta que ya usas

## Tipos de herramientas que reúne

- Editores de diseño (Figma, Penpot, Paper, Subframe…)
- Generadores de UI con IA (Claude Design, Uizard, Magic Patterns, Variant…)
- Herramientas de animación (Jitter, Shaders…)
- Plataformas code-first (Subframe, Pencil, Dessn, Lunagraph…)
- Herramientas de design systems (Tokens Studio, zeroheight…)
- Generadores de imagen (Midjourney, Quiver AI…)
- Asistentes de código con foco en diseño (Claude Code, Antigravity, Gemini, Kilo Code…)

## Cómo usarlo

1. Entra en [designtools.fyi](https://designtools.fyi/)
2. Elige tu **perfil** en la página principal (o navega por "Browse all tools")
3. Revisa el **ranking y descripción** de cada herramienta
4. Sigue el enlace a la web de la herramienta si te interesa
5. Suscríbete a la newsletter para recibir las novedades
