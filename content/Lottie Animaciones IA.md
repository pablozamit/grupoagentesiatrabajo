# Lottie Animaciones IA

Skill open source para **generar animaciones Lottie desde texto** usando agentes de IA (Claude Code, Codex, etc.).

**Repo**: [github.com/diffusionstudio/lottie](https://github.com/diffusionstudio/lottie)

## Qué hace

- Describe la animación en lenguaje natural
- La IA genera un archivo Lottie (JSON) listo para usar
- Perfecto para micro-interacciones UI sin abrir After Effects

## Usos

- Animaciones para botones, iconos, loaders
- Transiciones y micro-interacciones
- Ilustraciones animadas para web y apps
- Prototipado rápido sin herramientas de diseño
