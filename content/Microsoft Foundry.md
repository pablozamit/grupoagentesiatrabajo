# Microsoft Foundry

[Microsoft Foundry](https://ai.azure.com/) es la **plataforma unificada de Microsoft en Azure** para construir, desplegar y gobernar aplicaciones y agentes de IA a escala empresarial. Es la evolución de Azure AI Foundry y Azure AI Studio.

## Qué es

- Plataforma como servicio (PaaS) dentro de Azure para operaciones de IA empresarial
- Unifica **agentes, modelos y herramientas** bajo un mismo sistema de gestión
- Incluye **tracing, monitorización, evaluaciones**, control de acceso por roles (RBAC), redes y políticas
- Reemplaza a varios servicios previos de Azure AI con un único portal
- URL: [ai.azure.com](https://ai.azure.com/) (la dirección clásica sigue funcionando)

## Modelos disponibles

Foundry da acceso a **más de 1.900 modelos** de distintos proveedores:

| Familia | Ideal para |
|---------|-----------|
| **GPT-5** | El más capaz: razonamiento complejo, tareas multi-paso, multimodal |
| **GPT-4.1** | Mejor equilibrio capacidad-coste para cargas en producción |
| **GPT-4.1 mini** | El más rápido: baja latencia y alto rendimiento |
| **Claude** | Razonamiento avanzado, generación de código y tareas multimodales |
| **Grok** | Razonamiento, código y extracción de datos |
| **Mistral** | Generación de código, multilingüe y chat generalista |
| **DeepSeek-R1** | Razonamiento open-weight a escala |
| **Phi-4** | Modelo pequeño para dispositivos o entornos con recursos limitados |
| **Meta Llama** | Modelos abiertos para personalizar y hacer fine-tuning |

## Capacidades principales

### Construir agentes

- **Orquestación multi-agente** con SDKs para C# y Python
- **Catálogo de herramientas** con más de 1.400 conectores públicos y privados
- **Memoria** que retiene y recuerda contexto entre interacciones
- **Foundry IQ** para fundamentar respuestas en contenido empresarial o web con citas
- **Publicación** de agentes en Microsoft 365, Teams, BizChat o contenedores

### Operar y gobernar

- **Observabilidad en tiempo real** con métricas y seguimiento de modelos
- **Gestión centralizada** de todos los agentes, modelos y herramientas desde una sola sección
- **Controles enterprise**: autenticación para MCP y A2A, integración con AI Gateway y Azure Policy

## Novedades recientes

- **Model routing**: una sola API que enruta automáticamente al modelo adecuado
- **A2A agent endpoints**: expone agentes como endpoints Agent2Agent para que otros agentes los descubran y los llamen
- **Voice agents**: agentes con voz alojados en Foundry
- **Routines**: automatizaciones multi-paso reutilizables para flujos de agentes
- **Fabric IQ** y **Work IQ**: conecta agentes con datos de Microsoft Fabric y contenido de Microsoft 365

## SDKs disponibles

- Python
- C#
- JavaScript / TypeScript (preview)
- Java (preview)

También hay una **extensión para VS Code** para explorar modelos y desarrollar agentes directamente en tu editor.

## ¿Para quién es?

- **Desarrolladores de aplicaciones** que crean productos con IA, agentes, modelos y herramientas
- **Ingenieros de ML y científicos de datos** que ajustan modelos, ejecutan evaluaciones y gestionan despliegues
- **Administradores de IT e ingenieros de plataforma** que gobiernan recursos de IA, aplican políticas y gestionan acceso

## Precios

- La plataforma es **gratis de usar y explorar**
- El coste se aplica a nivel de despliegue: cada producto (modelos, agentes, herramientas) tiene su propio modelo de facturación
- También hay costes por el uso de los servicios subyacentes de Azure
