# Repositorio 400 Recursos de Diseño Gratuitos

[Repositorio en GitHub](https://github.com/noahelhadedy/400-free-design-resources) mantenido por [Noah Elhadedy](https://github.com/noahelhadedy).

## Qué es

Una lista curada de más de 400 recursos gratuitos de diseño — fuentes, iconos, ilustraciones, mockups, kits de UI, herramientas de color, medios de stock y más — agrupados para encontrar lo que necesitas rápido.

## Qué contiene

| Grupo | Qué encontrarás |
|-------|-----------------|
| **Gráficos y assets** | Fuentes, iconos, ilustraciones, modelos 3D, patrones, mockups |
| **Media** | Fotos de stock, vídeos, audio, animaciones Lottie |
| **Color y tipografía** | Generadores de paletas, gradientes, escalas tipográficas |
| **UI y componentes** | Kits de UI, design systems de referencia, generadores de CSS |
| **Herramientas** | Diseño y prototipado, wireframing, IA de diseño, logo, accesibilidad |
| **Email y slides** | Plantillas para emails y presentaciones |
| **Inspiración y aprendizaje** | Galerías, blogs, newsletters, podcasts y canales de YouTube |

## Para qué sirve

Cuando estás creando algo — una web, una app, una presentación, un vídeo, un proyecto con IA — y necesitas **recursos visuales de calidad sin pagar**: fuentes para tu marca, iconos para tu interfaz, mockups para presentar, fotos para el blog, paletas de color para tu diseño, etc.

En lugar de buscar en Google, aquí tienes una lista curada y organizada por categoría.

## Formatos disponibles

- **README del repo**: navegación por la web de GitHub
- **CSV** (`free-design-resources-notion.csv`): importable a Notion, Google Sheets, Excel, Airtable o cualquier hoja de cálculo

## Cómo usarlo

1. Entra al [repositorio](https://github.com/noahelhadedy/400-free-design-resources)
2. Busca la categoría que necesitas (por ejemplo, "Iconos" o "Paletas de color")
3. Haz clic en el recurso que te interese
4. Si quieres tener la lista completa editable, descarga el CSV
