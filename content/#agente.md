# #agente

Notas sobre agentes de IA:

- [[Hermes Agent]] - Agente que aprende de sus tareas
- [[Ajustes Avanzados de Hermes Agent]] - 10 ajustes para operación 24/7
- [[Google Jules]] - Agente de código de Google
- [[Kilo Code]] - Agente de código open source con 500+ modelos
- [[Claude Code]] - Agente de código oficial de Anthropic (CLI)
- [[Microsoft Foundry]] - Plataforma de Microsoft Azure para crear y gobernar agentes
- [[Memanto]] - Capa de memoria persistente open source para agentes
- [[HyperFrames]] - Genera vídeo desde HTML, diseñado para agentes
- [[Firecrawl]] - API de web scraping con servidor MCP para agentes
- [[Agent-Reach]] - Scaffolding open source para que un agente lea internet sin APIs
- [[last30days]] - Skill que busca en paralelo en Reddit, X, YouTube, HN y más, y sintetiza un brief de los últimos 30 días
- [[Acceso a internet desde agentes]] - Comparativa entre Firecrawl, Agent-Reach y /last30days para dar acceso a internet a tu agente
- [[AnythingLLM]] - Aplicación todo-en-uno de IA con agentes, documentos y multi-usuario
- [[Here.Now]] - Hosting web gratuito e instantáneo para agentes
