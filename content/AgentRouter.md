# AgentRouter

[AgentRouter](https://agentrouter.org/login) ofrece **100 $ de crédito API** para usar modelos de IA de alto rendimiento, solo por registrarte con tu cuenta de GitHub.

## Qué es

- 100 $ de uso gratuito de API al registrarse con GitHub
- Acceso a modelos de IA punteros a través de una API unificada
- Sin tarjeta de crédito para empezar

## Para qué sirve

Para experimentar con modelos de primer nivel sin coste inicial. Útil si quieres:

- Probar un modelo concreto para una tarea específica (generación de código, análisis, etc.)
- Comparar el rendimiento de varios modelos en tu flujo de trabajo
- Construir prototipos rápido sin configurar facturación

## Cómo empezar

1. Ve a [agentrouter.org/login](https://agentrouter.org/login)
2. Inicia sesión con tu cuenta de GitHub
3. Obtén tu API key
4. Úsala en tu agente o proyecto

## Compatibilidad

- Funciona con **[[Claude Code]]** (agente CLI de Anthropic)
- **No funciona con [[Hermes Agent]]** (usa su propio gateway basado en OpenRouter)

> **Nota**: al ser una oferta de bienvenida, podría caducar. Si el link deja de funcionar, búscalo como "AgentRouter 100$ GitHub" para localizar posibles extensiones o equivalentes.
