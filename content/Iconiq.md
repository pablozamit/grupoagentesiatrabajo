# Iconiq

[Iconiq](https://iconiqui.com/introduction) es una **colección curada de componentes UI reutilizables** pensada para copiar y pegar en tu proyecto mediante el flujo de trabajo del registro de shadcn.

## Qué es

- Librería de componentes UI open source
- Se entrega a través del **flujo shadcn registry**: los componentes se copian como archivos locales a tu codebase, no se instalan como dependencia cerrada
- Enfoque en **minimalismo**: motion contenido, interacciones familiares
- Cada componente se puede inspeccionar y modificar sin pelearte con una abstracción

## Filosofía

El objetivo no es solo ahorrar tiempo: es **fijar una base de calidad** que mantenga la coherencia del producto a medida que crece.

- **Movimiento con propósito**: las transiciones confirman una acción, orientan al usuario o preservan contexto espacial. Nunca son decorativas
- **Patrones familiares**: las interacciones son predecibles y alineadas con lo que la gente ya conoce de productos bien hechos
- **Archivos locales**: motion, estilos, estructura y accesibilidad evolucionan dentro de tu propio código, no detrás de la frontera de un paquete

## Qué incluye

### Componentes UI estándar

Accordion, Alert, Alert Dialog, Autocomplete, Avatar, Badge, Breadcrumbs, Button, Button Group, Card, Carousel, Calendar, Charts, Checkbox, Checkbox Group, Collapsible, Color Picker, Combobox, Context Menu, Dialog, Drawer, Dropdown, File Upload, Hover Card, Popover, Progress, Radio Group, Select, Separator, Selection Toolbar, Skeleton, Slider, Spinner, Switch, Table, Tabs, Toggle, Toggle Group, Tooltip.

### Componentes "Special One"

Icon Bar, Infinite Ribbon, Origin Button, FAQ Pro, Theme Toggle, Verified Badge.

### Base y textos

- **Foundation**: Typography
- **Texts**: Dia Text, Shimmer Text, Text Inertia, Typewriter

## Por qué encaja con vibecoding

- Compatible con el **flujo shadcn**: pegas el componente, lo ajustas, sigues
- Cada componente es **legible y editable** — ideal para que un agente de IA lo modifique
- Los componentes están aislados, sin abstracciones opacas
- Estilo neutro que se adapta a la marca de cada producto
