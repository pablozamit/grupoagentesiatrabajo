# ZenMux AI — Modelos gratis (GLM 5.2, Kimi K2.7, Step 3.7)

[zenmux.ai](https://zenmux.ai) — API gratuita con modelos abiertos de último nivel. Sin tarjeta de crédito. Una API key compatible con OpenAI.

## Modelos gratis incluidos

- **GLM 5.2** — Mejor modelo abierto de coding. SWE-bench Pro: 62.1 (GPT-5.5: 58.6). 1M contexto, 128K salida. Pesos abiertos. ~1/6 del coste de GPT-5.5.
- **Kimi K2.7 Code** — Modelo abierto de 1 billón de parámetros (lanzado 12 junio 2026).
- **Step 3.7 Flash** — Rápido, ideal para loops de agente ágiles.

## Cómo usar

1. Registrarse en [zenmux.ai](https://zenmux.ai) con Gmail
2. Ir a modelos → elegir GLM 5.2 (free)
3. "API request" → crear API key
4. Base URL: `https://zenmux.ai/api/v1` (compatible OpenAI)
5. Usar en Claude Code, Cline, Cursor, Zed, Hermes Agent, OpenClaw, etc.

## ⚠️ Temporal

- El tier gratis tiene límites, no es para builds maratón
- Es una ventana de prueba limitada — puede cerrar en cualquier momento
