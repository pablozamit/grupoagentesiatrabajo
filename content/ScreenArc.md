# ScreenArc

Alternativa gratuita y open source a **Screen Studio** (que cuesta $29/mes o $348/año). Graba la pantalla con efecto cinematico: seguimiento inteligente del cursor, zoom y paneo suaves, desenfoque de movimiento. Windows, macOS y Linux. Licencia GPL-3.0.

## Qué lo diferencia de Screen Studio

| | Screen Studio | ScreenArc |
|---|---|---|
| Precio | $348/año | $0 |
| Plataformas | Solo Mac | Windows, macOS, Linux |
| Código | Cerrado | Open source (GPL-3.0) |
| Modificable | No | Sí, puedes forkearlo o construir encima |

Usa Electron, React y FFmpeg para conseguir el efecto cinematico.
