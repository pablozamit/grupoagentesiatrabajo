# VGGT

VGGT es un modelo que estima parámetros de cámara, profundidad, mapas de puntos y correspondencias 3D a partir de una o varias vistas de una escena. El checkpoint original no es comercial; VGGT-1B-Commercial tiene condiciones distintas que permiten uso comercial con exclusiones y requieren solicitar acceso.
