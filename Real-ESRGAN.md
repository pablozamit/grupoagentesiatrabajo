# Real-ESRGAN

**Real-ESRGAN** es un proyecto de restauración y ampliación de imágenes y vídeo mediante redes neuronales, con modelos específicos para material general y anime. El detalle generado es una estimación, no una recuperación garantizada del original; el código usa licencia BSD de tres cláusulas.
