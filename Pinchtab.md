# Pinchtab

Da a cualquier agente de IA control total del navegador mediante una API HTTP. Binario de solo 12 MB.

## Características

- Lanza y gestiona sus propias instancias de Chrome
- Expone un árbol DOM accesible con referencias estables a elementos
- Click, escribir, scroll, navegar — todo vía HTTP
- Stealth integrado que esquiva detección de bots en sitios principales
- Sesiones persistentes — inicia sesión una vez, se mantiene entre reinicios
- Orquestación multi-instancia con dashboard en tiempo real
