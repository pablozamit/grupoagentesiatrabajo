# Text-to-CAD

**Text-to-CAD** es una herramienta open source que genera archivos CAD a partir de descripciones en texto. Ha superado las **10.000 estrellas** en GitHub. Creado por [Jake Fitzgerald](https://x.com/earthtojake) y el equipo de [Zoo](https://zoo.dev).

## Qué genera

| Formato | Uso |
|---------|-----|
| **STEP** | Archivos CAD paramétricos estándar |
| **URDF, SDF** | Simulación robótica (ROS, Gazebo) |
| **STL, 3MF, GLB** | Mallas 3D para impresión y visualización |
| **G-code** | Listo para impresoras 3D |
| **DFM checks** | Verificaciones de manufacturabilidad para SendCutSend y otros servicios |

## Características

- **100% gratuito y open source**
- Genera modelos CAD editables, no solo mallas
- Orientado a ingeniería mecánica y robótica
- Integración con servicios de fabricación

## Por qué importa

A diferencia de las herramientas texto→3D que solo generan mallas (como Meshy o 3D AI Studio), Text-to-CAD produce archivos STEP paramétricos que se pueden editar en software CAD profesional (Fusion 360, SolidWorks, FreeCAD). Es el equivalente CAD de lo que `text-to-code` es para programación.
