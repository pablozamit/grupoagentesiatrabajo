# UniRig

[UniRig](https://github.com/VAST-AI-Research/UniRig) («One Model to Rig Them All», SIGGRAPH 2025) genera automáticamente el esqueleto (rig) de modelos 3D muy diversos —humanoides, animales, objetos— para dejarlos listos para animar. Licencia MIT, ~2.113 ⭐.

## Puntos clave

- **Un solo modelo** para rigging automático de clases de assets muy distintas, en lugar de rigs a mano por personaje.
- **Encaja en la tubería de agentes 3D**: generar el modelo ([[TRELLIS.2]], [[Hunyuan3D 2.1]]), riggearlo con UniRig y animarlo en Blender.
