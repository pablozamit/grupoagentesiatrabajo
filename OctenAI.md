# OctenAI

**OctenAI** es un motor de búsqueda para agentes de IA que afirma ser el más rápido del mundo: **62ms P50** (vs 372ms de Exa). Construido por [OctenAI](https://octenai.com) × [Monid AI](https://monid.ai).

## Características

- **62ms P50** de latencia — 6× más rápido que Exa (372ms)
- Diseñado específicamente para agentes, no para humanos
- Puede dividir una tarea en miles de búsquedas concurrentes
- Se integra en Claude Code, Codex y otros agentes

## Instalación

```bash
# Desde monid.ai
```

## Por qué importa

Los buscadores tradicionales están optimizados para humanos: una consulta, una página de resultados. OctenAI está diseñado para el patrón de los agentes: muchas consultas paralelas, respuestas en formato machine-readable, latencia mínima.
