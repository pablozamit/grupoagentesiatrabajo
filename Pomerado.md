# Pomerado

**Pomerado** ([Pomerado/pomerado](https://github.com/Pomerado/pomerado)) es una herramienta **open source** (MIT) que **convierte cualquier web en una API o un servidor MCP en minutos**, para que tu agente deje de "cliquear como un turista perdido" y llame directamente a los datos. Se presenta como *"core integration minting harness"* de código abierto, dentro de una startup **YC F26**. Se difundió desde la cuenta de [Product Hunt](https://x.com/ProductHunt/status/2111144928504156329) (15 oct 2026), que menciona a **@pomeradoai**.

## Qué hace

- **Traduce las webs que ya existen** en una **API o MCP** que tu agente puede llamar.
- El planteamiento: **la automatización por navegador no siempre es el mejor camino**; a veces es más rápido y fiable convertir la web en un servicio estructurado (traducir en lugar de *scrapear*).
- El tuit afirma que funciona incluso con sitios complejos como **Google Flights** (atribución del anunciante).
- El núcleo ("minting harness") es **open source**; hay una parte de producto alrededor.

## Datos y atribución

- **Estrellas**: GitHub verificado el 17 oct 2026, **24 ⭐** y 3 forks (TypeScript). Repo creado el 5 oct 2026, muy reciente.
- **Licencia**: MIT (según la descripción y el registro de GitHub).
- **Contexto**: YC F26. Las cifras y el ejemplo de Google Flights vienen del anuncio; el proyecto es nuevo y aún no tiene benchmark independiente.

## Por qué importa

Es la vía **"traducir la web"** en el debate sobre cómo acceder a internet desde un agente, alternativa a la vía **"automatizar el navegador"** (Browser Use, Stagehand, Browser Harness).
