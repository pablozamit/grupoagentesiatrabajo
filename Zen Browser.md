# Zen Browser

[Zen Browser](https://zen-browser.app) — fork open source de Firefox (41k ⭐ en GitHub) multiplataforma con bloqueo de trackers automático, diseñado para productividad y **controlable por agentes de IA**.

## Características clave

- **Workspaces**: organiza pestañas por actividad (trabajo, estudio, compras)
- **Glance**: previsualización de enlaces en pop-up sin abrir nueva pestaña (tecla + clic)
- **Split View**: dos pestañas lado a lado, persistente tras reinicios
- **Compact Mode**: oculta la barra lateral cuando no se usa
- **Zen Mods**: 79+ addons comunitarios para personalizar la UI
- **Firefox Sync**: sincroniza marcadores e historial con cuenta Mozilla
- Licencia: **Mozilla Public License 2.0**

## Controlable por agentes de IA

Zen Browser puede ser manejado por agentes de IA de varias formas:

| Método | Qué permite |
|--------|-------------|
| **zen-mcp** (recomendado) | Servidor MCP específico vía WebSocket/BiDi. ~20 herramientas para navegación, interacción, extracción. Para Claude, Cursor y agentes modernos |
| **Playwright / Selenium** | Automatización estándar (es Firefox-based) |
| **WebDriver BiDi** | Control programático avanzado (clics, navegación, datos) |
| **Extensiones Firefox** | Compatible con todo el ecosistema de addons |

Ventajas para agentes: ligero, privado, sin tracking, ideal para automatizaciones de navegación autónoma.
