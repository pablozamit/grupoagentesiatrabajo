# Google Jules

[Jules](https://jules.google.com/) es un agente de código asíncrono de Google que trabaja en tu repositorio GitHub.

## Qué es

- **Agente de código autónomo**: Lee tu código, entiende lo que quieres y lo hace solo
- **Asíncrono**: Le das una tarea, te vas, vuelve cuando terminó
- **Integración con GitHub**: Funciona dentro de tu flujo de trabajo en GitHub
- **Seguridad**: Tu código no se usa para entrenar modelos

## Para qué sirve

- Escribir tests
- Arreglar bugs
- Añadir features nuevas
- Actualizar dependencias
- Añadir documentación

## Cómo funciona

1. Conectas tu repositorio de GitHub
2. Le dices qué quieres hacer (por ejemplo: "arregla el bug del login")
3. Clona tu código en una máquina virtual segura de Google Cloud
4. Hace los cambios y te presenta un diff
5. Revisas, aceptas o pides cambios
6. Abre un pull request

## Características

- Trabaja en segundo plano mientras haces otras cosas
- Changelogs en audio
- Acceso a internet para probar y depurar
- No toca tu código sin permiso (con supervisión humana)

## Requisitos

- Cuenta de GitHub
- Membership de Google AI (Introductory, AI Pro, o AI Ultra)
- 18+ años
- Solo inglés (de momento)
