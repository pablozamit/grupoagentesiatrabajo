# CLI-Anything

**CLI-Anything** es un proyecto de código abierto de la Universidad de Hong Kong (HKUDS) que genera automáticamente una interfaz de línea de comandos (CLI) para cualquier programa, de modo que un agente de IA lo controle ejecutando comandos en vez de mirar capturas de pantalla, reconocer botones y hacer clic.

Analiza el código fuente y las interfaces de bajo nivel del programa y crea el conjunto de comandos y una **skill** con la que el agente aprende a usarlo. Incluye **CLI-Hub**, un repositorio donde el agente busca e instala CLIs ya creadas (`pip install cli-anything-hub`, luego `cli-hub install`).

Cubre programas como Blender, GIMP, LibreOffice, OBS, Godot, Obsidian y FreeCAD.

Repositorio: [github.com/HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything) (licencia Apache 2.0).
