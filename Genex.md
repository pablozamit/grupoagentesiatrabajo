# Genex

**Genex** es una aplicación de escritorio para desarrollo de juegos con IA. El bookmark de [@genex_games](https://x.com/genex_games/status/2112276766718845024) anuncia la versión 0.1.10 para Windows y la presenta como una aplicación open source para crear juegos con cualquier IA.

La página enlazada es [genex.games/desktop](https://genex.games/desktop). La afirmación de código abierto y la versión corresponden al anuncio de X; hay que comprobar el repositorio, la licencia y qué modelos/proveedores admite antes de tratarlo como dependencia estable.

## Encaje

Genex entra en el cruce de [[Vibecoding]], herramientas de juegos y agentes que editan proyectos locales. Se complementa con [[Godot]], [[Unreal Engine Skills para Claude Code]], [[Three.js Game Skills (Majid Manzarpour)]] y [[Sorceress]].
