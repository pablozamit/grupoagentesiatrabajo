# Colección Csaba Kissi

Csaba Kissi ([@csaba_kissi](https://x.com/csaba_kissi)) recopiló 5 herramientas open source y gratuitas para desarrolladores:

## iconsax.dev

[iconsax.dev](http://iconsax.dev) — 7.000+ iconos SVG gratuitos. Alternativa open source a librerías de iconos comerciales con gran variedad de estilos. Para muchísimos más iconos hand-drawn (71.000+), ver [[Koboyo Icons]].

## csscursors.colorion.co

[csscursors.colorion.co](http://csscursors.colorion.co) — Colección open source de cursores CSS listos para usar en proyectos web. Alternativa visual a los cursores nativos del sistema.

## opencli.info

[opencli.info](http://opencli.info) — Convierte tu navegador Chrome en comandos estables para agentes de IA. Permite darle a tu agente acceso controlado al navegador sin depender de APIs externas.

## recent.design

[recent.design](http://recent.design) — Inspiración de diseño gratuita desde los mejores sitios web. Galería curada actualizada con tendencias actuales de diseño UI/UX.

## componentry.dev

[componentry.dev](http://componentry.dev) — Componentes UI animados open source para React. Alternativa a bibliotecas de componentes con animaciones integradas.
