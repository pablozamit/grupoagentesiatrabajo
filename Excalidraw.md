# Excalidraw

[Excalidraw](https://github.com/excalidraw/excalidraw) es una pizarra virtual open source (MIT) para dibujar diagramas con aspecto de boceto hecho a mano. En flujos con agentes sirve como lienzo de bocetos rápidos que el agente puede generar o usar como punto de partida de un diseño.
