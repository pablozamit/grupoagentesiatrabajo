# Postiz

[Postiz](https://postiz.com) programa y publica en varias redes sociales desde un calendario. Ofrece adaptación por canal, API pública, CLI y MCP para agentes; la [documentación](https://docs.postiz.com) separa cloud, autohospedaje y desarrollo.

## Uso con agentes

El agente prepara publicaciones y horarios mediante las conexiones del producto. Revisar contenido y cuenta destino: capacidad de API no autoriza una campaña. Comprobar por canal formato, OAuth, cuotas y resultado de publicación.

En el flujo [[Vugola]], Postiz distribuye clips y [[Hermes Agent]] coordina. No convierte automáticamente los clips en contenido monetizable ni garantiza tener todas las cuentas conectadas.

## Operación propia

La documentación incluye instalación y configuración de proveedores. Autohospedar no elimina mantenimiento, almacenamiento ni requisitos de cada red. La ruta propia no hace gratis el plan alojado.
