# Create Blender Story Video

[Create Blender Story Video](https://github.com/yoruuuchan/create-blender-story-video) es una skill de código abierto con licencia MIT para producir vídeos 3D con agentes como Codex, Claude Code y Qoder: conecta estilo visual, guion gráfico, escenas de [[Blender MCP|Blender]], renderizado recuperable por fotogramas PNG y edición en DaVinci Resolve. Valida el estado de producción y comprueba especificaciones, decodificación completa y hash SHA-256 del archivo final. El supervisor de renderizado recuperable está verificado en Windows con PowerShell; la validación, codificación y comprobación multimedia admiten Python 3.11+ en Windows, Linux y macOS. Requiere Blender y Blender MCP configurados, además de las herramientas de edición y codificación correspondientes; no los instala automáticamente.
