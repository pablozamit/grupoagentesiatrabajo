# TRELLIS.2

[TRELLIS.2](https://github.com/microsoft/TRELLIS.2) es el modelo de Microsoft que genera un asset 3D completo a partir de una sola imagen: geometría y apariencia listas para usar. Se apoya en «Structured Latents» nativos y compactos (paper [arXiv:2512.14692](https://arxiv.org/abs/2512.14692)); el modelo de 4B parámetros está en Hugging Face ([microsoft/TRELLIS.2-4B](https://huggingface.co/microsoft/TRELLIS.2-4B)) con [demo online](https://huggingface.co/spaces/microsoft/TRELLIS.2). Código MIT, ~12.904 ⭐.

## Puntos clave

- **Una imagen entra, un modelo 3D sale**: pensado para la tubería imagen→asset en juegos, producto y prototipado con agentes.
- **Latentes estructurados compactos**: la representación 3D nativa del modelo busca calidad alta con menos cómputo.
- **Ecosistema**: wrappers para ComfyUI y plugins para Blender y Unreal mantenidos por la comunidad.
