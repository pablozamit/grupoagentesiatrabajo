# Fumadocs

**Fumadocs** ([fumadocs.dev](https://www.fumadocs.dev), de Fuma Nama, repo `fuma-nama/fumadocs`, MIT, 13.2k ⭐) es el **framework React para webs de documentación**: bloques componibles estilo headless para no reconstruir un docs site en cada proyecto. Lo avalan shadcn, Vercel (Turbo DX) y el creador de Million.js.

## Capas (Content → Core → UI)

- **fumadocs-mdx**: MDX elegante en tu framework (Next.js, Astro, Waku, TanStack Start, React Router)
- **fumadocs-core**: headless (búsqueda, adaptadores de contenido, extensiones Markdown)
- **fumadocs-ui**: tema bonito por defecto + CLI estilo shadcn (`npx @fumadocs/cli add`)
- Extensiones: **OpenAPI** (docs de tu schema), **Obsidian** (Markdown estilo Obsidian), **llms.txt** (vía Fumapress), playground interactivo, search Orama/Algolia

```bash
pnpm create fumadocs-app
```

## Fumapress (vía fácil)

Framework con plugins para quien no quiere configurar: routing automático, llms.txt, MCP y más.
