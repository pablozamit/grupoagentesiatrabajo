# AutoVPN

Proyecto anunciado como un proxy automático sobre circuitos Tor. La publicación lo llama versión 2.0, pero el README consultado todavía lo identifica como versión 1.0 y ofrece muy poca información sobre requisitos y funcionamiento. El repositorio incluye un script de shell que se ejecuta con privilegios elevados; no se ha ejecutado ni auditado.

La falta de documentación suficiente y la discrepancia de versiones impiden recomendar su instalación sin revisar primero el código, sus dependencias y los cambios que realiza en el equipo.

Repositorio: [hack8us/autovpn](https://gitlab.com/hack8us/autovpn).
