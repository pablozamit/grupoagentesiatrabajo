# Vibecode It Yourself

**Vibecode It Yourself** es un sitio web de [Flavio Copes](https://flaviocopes.com) con guías y prompts para reemplazar SaaS que pagas por versiones vibecodeadas por ti mismo.

- **Web:** [vibecodeityourself.com](https://vibecodeityourself.com)

Incluye **33 reemplazos** categorizados por tiempo de construcción (Tonight 10, Weekend 13, Side Quest 10) y por área:

### Personales
- **Linktree** (30 min) — Página de enlaces
- **Readwise Reader** (2 días) — Guardar links para leer después
- **TinyPNG Pro** (60 min) — Compresión de imágenes
- **CleanMyMac** (8h) — Limpieza de disco en macOS

### Productividad
- **Calendly** (6h) — Booking de reuniones
- **Notion** (10h) — Wiki de equipo
- **Trello** (3h) — Tablero kanban
- **Linear** (12h) — Issue tracker
- **Slack** (4 días) — Chat de equipo
- **Loom** (10h) — Grabación de pantalla
- **Miro** (12h) — Pizarra colaborativa
- **Canny** (10h) — Feedback de usuarios

### Marketing

- **Buffer** (8h) — Programación de redes sociales
- **Mailchimp** (12h) — Newsletters
- **Kit** (10h) — Newsletter para creadores
- **Bitly** (90 min) — Acortador de links
- **Hotjar** (3 días) — Analytics de visitantes
- **Plausible** (8h) — Analytics simple
- **SurveyMonkey** (4h) — Encuestas

### Operaciones

### Ventas

### Soporte

Cada entrada incluye stack técnico sugerido (Astro + HTMX/Alpine + D1/R2/Workers), tiempo estimado y prompt completo para tu agente de código.
