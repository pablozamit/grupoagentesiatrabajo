# GSAP

[GSAP](https://github.com/greensock/GSAP) (GreenSock Animation Platform) es una librería JavaScript de animación para la web: timelines, easings y animación de propiedades con buen rendimiento. Es la capa de movimiento habitual en interfaces y motion graphics web; [[HyperFrames]] la integra en su skill de animación. El proyecto mantiene skills oficiales para agentes ([greensock/gsap-skills](https://github.com/greensock/gsap-skills), citadas en [[Stack de vídeo con agentes (Dumble)]]).
