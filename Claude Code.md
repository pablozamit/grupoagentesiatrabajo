# Claude Code

[Claude Code](https://www.anthropic.com/claude-code) es el **agente de código oficial de Anthropic** que trabaja directamente en tu terminal con tu código base.

## Qué es

- **CLI agent** (interfaz de línea de comandos) desarrollado por Anthropic
- Usa los modelos **Claude Opus 4**, **Sonnet 4** y **Haiku** según la tarea
- Lee y entiende tu código base completo
- Edita archivos, ejecuta comandos, busca en el código y trabaja de forma autónoma
- Compatible con el protocolo **MCP** para extender sus capacidades

## Para qué sirve

- Programar en pareja con Claude sin salir de la terminal
- Ejecutar tareas largas y autónomas sobre un proyecto: refactorizar, migrar, documentar, escribir tests
- Aplicar cambios coordinados en muchos archivos a la vez
- Investigar bugs leyendo el código y proponiendo arreglos

## Cómo empezar

1. Instala el CLI de Claude Code desde [anthropic.com/claude-code](https://www.anthropic.com/claude-code)
2. Inicia sesión con tu cuenta de Anthropic o con una API key
3. Desde la raíz de tu proyecto, ejecuta `claude`
4. Pídele tareas sobre tu código: leer, editar, ejecutar tests, etc.
