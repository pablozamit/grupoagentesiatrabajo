# Openverse

[Openverse](https://openverse.org) es un buscador y una API abierta de contenido con licencias libres mantenido por WordPress.org: imágenes y audio (música y efectos) reutilizables, consultables desde una sola API REST gratuita (`api.openverse.org/v1/`). En un pipeline de vídeo con agentes cubre la capa de sonidos y material visual libre para cada escena.
