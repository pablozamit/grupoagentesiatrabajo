# OpenSEO

**OpenSEO** es una **suite de SEO pensada para agentes**: keyword research, rank tracking, research de dominios y backlinks, auditorías de sitio y visibilidad en IA, con implementación open source y conexión por MCP para Claude, Codex y otros agentes.

## Qué es

- **Suite completa**: Keyword Research, Saved Keywords, Rank Tracking, Domain Overview, Backlinks, Site Audit, AI Visibility y Prompt Explorer (comparar respuestas entre modelos)
- **Site Audit**: crawl de páginas con status codes, títulos, metas, headings, indexabilidad, alt de imágenes, enlaces y tiempo de respuesta, más checks opcionales de Lighthouse (rendimiento, SEO, accesibilidad)
- **Renderizado JavaScript (oct 2026)**: según el anuncio de OpenSEO, las auditorías ya pueden renderizar el sitio como un navegador real — desbloquea indexing preciso en SPAs y app shells y esquiva detecciones de bot agresivas (el anuncio cita hosts como SiteGround)
- **Para agentes**: OpenSEO MCP y Search Console MCP conectan la suite con Claude, Codex y cualquier cliente MCP; además publica Skills con workflows cerrados (p. ej. auditoría SEO)
- **Open source + self-hosting**: la implementación es abierta y hay guías de self-hosting; también existe la app alojada y utilidades gratis sin registro (como el simulador de SERP)
