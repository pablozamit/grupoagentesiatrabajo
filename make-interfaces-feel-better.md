# make-interfaces-feel-better

Skill para agentes (Claude Code, Codex, Cursor) que enseña a las IAs los pequeños detalles que hacen que una interfaz se sienta mejor. Más de 30.000 instalaciones.

- **Autor**: Jakub Krehel ([@jakubkrehel](https://x.com/jakubkrehel))
- **Web**: [jakub.kr/skills/make-interfaces-feel-better](https://jakub.kr/skills/make-interfaces-feel-better)
- **Instalación**: `npx skills add jakubkrehel/make-interfaces-feel-better`

Basado en el artículo "Details that make interfaces feel better". Cubre tipografía, estados hover, alineación óptica, radios de borde concéntricos, sombras, rendimiento y más.

Uso: después de instalar, ejecutar `/make-interfaces-feel-better` para empezar.
