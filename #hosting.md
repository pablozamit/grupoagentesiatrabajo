# #hosting

Notas sobre hosting/publicar en internet:

- [[Vercel]] - Plataforma de hosting
- [[AnythingLLM]] - Aplicación auto-hospedada tipo ChatGPT privado
- [[Here.Now]] - Hosting web gratuito e instantáneo para agentes
- [[Oracle Cloud Free Tier]] - VPS gratis con 4 OCPU + 24 GB RAM (Always Free)
- [[VPS]] - Servidores privados virtuales gratuitos y económicos
- [[OpenShip]] - Plataforma open source para desplegar apps, bases de datos y servidores de correo en tu propia infraestructura
- [[free-for.dev]] - Lista de 1.600+ servicios con tiers gratuitos (Oracle, Cloudflare, Vercel, Supabase...), 132k ⭐, actualizada a diario
- [[VPN privada con VPS (3x-ui + VLESS REALITY)]] - Monta tu propia VPN en un VPS con panel 3x-ui y protocolo VLESS/REALITY
- [[HarnessRouter + UHP]] - Interfaz self-hosted para agent harnesses: un docker run con tus keys y tus datos en la caja
- [[Cloudflare Agentic Inbox]] - Email self-hosted en tu cuenta de Cloudflare (Workers, Durable Objects, R2)
- [[InstaCloud]] - Cloud agent-native (YC): Postgres + storage + cómputo branchable que tu agente opera (CLI/skill/MCP, self-host con insta-oss)
- [[Fly Sprites (Jev)]] - Un ordenador Firecracker por agente: hiberna, despierta por webhook, $30 trial, conectores sin keys

- [[Maillayer]] - Plataforma de email en un contenedor, con SQLite y proveedor de envío externo

- [[Nebula]] - Red overlay / mesh VPN open source: conecta servidores y máquinas de agentes sin abrir puertos
- [[tailcat]] - Túneles WireGuard puntuales sobre los relays DERP de Tailscale, sin cuenta ni root
- [[Instabox]] - Da a cada agente su propio ordenador en la nube (efimero, con snapshot y URL publica)
- [[SPACE (Perplexity)]] - Sandbox de microVMs Firecracker para ejecutar código de agentes, self-hosted (Apache 2.0)


- [[MaxClaw]] - Agente OpenClaw alojado: se despliega en segundos y evita montar VPS, Docker y claves de API
