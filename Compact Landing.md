# Compact Landing

[Compact Landing](https://compact-skill.dev) es una **skill open source** para que agentes de IA creen landing pages compactas, táctiles y premium con un solo prompt. Sin frameworks, sin bloat.

## Qué es

- Skill reutilizable para tu agente de IA
- Genera páginas de producto compactas con un CTA claro
- Estilo táctil, premium, minimum viable landing
- Open source (MIT)

## Cómo se usa

Instálala en tu agente:

```bash
npx skills add Danilaa1/compact-landing-skill
```

Luego pídele a tu agente:

```
Use $compact-landing to create a premium compact landing page for this product: [descripción]
```

## Qué hace el agente

Antes de generar, pregunta por:

- Producto y CTA
- Layout (5 variantes)
- Tema y bordes
- Animaciones y carga de contenido

## Casos de uso

- Páginas de producto estrechas / package demos
- Landing pages de herramientas para desarrolladores
- Intros de documentación
- Micro-SaaS pulidos
