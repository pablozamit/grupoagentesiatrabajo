# Kilo Code

[Kilo Code](https://kilo.ai/) es un **agente de código con IA open source** que te permite programar con ayuda de inteligencia artificial en tu editor, terminal o en la nube.

## Qué es

- **Open source** con licencia Apache 2.0
- Funciona donde tú trabajas: **VS Code, JetBrains, CLI, Slack, Cloud**
- Acceso a **más de 500 modelos de IA** desde un mismo lugar
- **3 millones de usuarios** y más de 40 billones de tokens procesados
- Ganador de "Producto Open Source del Mes"

## Modos de agente

Kilo Code tiene 5 modos especializados para cada situación:

- **Preguntar** (Ask): preguntas sobre tu código sin modificarlo
- **Arquitecto** (Architect): planifica funciones complejas antes de escribir nada
- **Código** (Code): escribe, refactoriza y entrega código listo para producción
- **Depurar** (Debug): identifica y corrige errores leyendo trazas
- **Personalizado** (Custom): crea tus propios modos

## Instalación en la terminal (CLI)

Una de las formas más cómodas de empezar es por línea de comandos:

1. Entra en [kilo.ai](https://kilo.ai/) y crea una cuenta gratis (no requiere tarjeta)
2. Sigue las instrucciones de instalación de CLI en la documentación oficial
3. Inicia sesión desde la terminal con tu cuenta
4. Ejecuta `kilo` para abrir el agente
5. Empieza a pedirle tareas sobre tu código

Una vez dentro puedes:

- Pedirle que lea tu código y lo entienda
- Crear funciones nuevas a partir de una descripción
- Refactorizar código existente
- Ejecutar tests
- Hacer commits y abrir pull requests

## Modelos gratuitos que rotan cada mes

Una de las cosas más útiles para los alumnos: Kilo ofrece una selección de **modelos gratuitos que van rotando aproximadamente cada mes**. Esto te permite:

- Probar modelos punteros sin pagar (familias Llama, Qwen, DeepSeek, GLM, Nemotron…)
- No atarte a un único proveedor
- Aprender a trabajar con varios modelos y ver cuál se adapta mejor a tu tarea

Para ver qué modelos están disponibles ahora mismo y cuáles son gratis este mes, entra en [kilo.ai](https://kilo.ai/) y revisa la sección de modelos.

## KiloClaw: tu agente 24/7 en la nube

Kilo también ofrece **KiloClaw**, un agente gestionado que vive en la nube:

- Se despliega en menos de 60 segundos con un clic
- Funciona 24/7 sin tener tu PC encendido
- Se conecta a **Telegram, Discord o Slack**
- Ejecuta comandos de terminal, controla navegadores y actúa por ti
- Acceso a los 500+ modelos sin recargo

Ideal para tareas programadas, automatizaciones o tener un asistente siempre disponible.

## Por qué importa para vibecodear

- Es open source y gratis para empezar
- Funciona en tu editor o en tu terminal, sin cambiar de herramienta
- Soporta **MCP (Model Context Protocol)** para conectar herramientas externas
- Entiende tu código base completo, no solo el archivo abierto
- Funciona con prácticamente cualquier lenguaje de programación
