# Game UI Database (blog gratis)

**Game UI Database** ([gameuidatabase.com](https://www.gameuidatabase.com), de Edd Coates [@EddCoates](https://x.com/EddCoates)) es la referencia de UI en juegos: **1.900+ juegos, 76.000+ pantallas** buscables por plataforma, género, estética, color o hex. Ahora suma un **blog con ~200 páginas de tutoriales UI/UX gratis**: sin anuncios, sin paywalls, sin email. Declarado **AI-free zone** y respuesta directa a los cursos de $900. 100.8k views.

Primera entrega: esquemas de control cross-plataforma y layouts.
