# Hunyuan3D 2.1

[Hunyuan3D 2.1](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1) es el modelo de Tencent que convierte imágenes en assets 3D de alta fidelidad con materiales PBR «production-ready» (su descripción oficial). ~4.433 ⭐.

## Puntos clave

- **Imagen→asset 3D** con geometría detallada y materiales PBR (albedo, rugosidad, metalicidad) pensados para producción.
- **Ecosistema**: hay paquetes portables para Windows y wrappers de ComfyUI mantenidos por la comunidad.
