# Tweakpane

[Tweakpane](https://github.com/cocopon/tweakpane) es una librería open source (MIT) de paneles de control compactos para páginas web, inspirada en dat.GUI: sliders, selectores de color y monitores para ajustar parámetros y observar valores en vivo. Sin dependencias, extensible con plugins, con soporte móvil y tipos de TypeScript. En un flujo de animación por código sirve para afinar a mano los números finos de una escena.
