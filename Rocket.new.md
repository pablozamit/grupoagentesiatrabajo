# Rocket.new

**Rocket.new** ([rocket.new](https://www.rocket.new), [@rocketdotnew](https://x.com/rocketdotnew)) es un **AI app builder full-stack**: describes la app una vez y genera frontend (Next.js/Flutter), backend, deploy y dominios — 1.5M+ builders en 180 países. Diferencia clave: la **base de datos es el punto de partida, no un afterthought** (Supabase: schema, auth, RLS y queries entran en la generación antes de escribir código). Sin lock-in: código descargable + sync GitHub.

## El caso: app de finanzas en un prompt (Nelly, 169k views)

Con un prompt Rocket generó el dashboard (budget tracker, categorías, inversiones, metas visuales, sugerencias) y con Supabase montó auth + budgets/transactions/goals con updates en tiempo real. Móvil y desktop.

## Stack que integra

Supabase, Stripe, Figma, GitHub, OpenAI, Twilio + staging/producción, SEO, analytics y rollback. Tres pilares: Solve (research), Build (generar), Intelligence (vigilar competencia).
