# ui-ux-pro-max

[ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) es una skill open source (MIT) que da a los agentes inteligencia de diseño para construir interfaces profesionales en varias plataformas: combinaciones de estilos, colores y tipografías que funcionan juntas (el hilo que la difundió hablaba de 80 looks predefinidos).
