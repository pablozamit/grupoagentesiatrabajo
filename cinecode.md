# cinecode

**cinecode** ([github.com/sarpstar/cinecode](https://github.com/sarpstar/cinecode)) es una skill open source (MIT) para crear películas con código dentro de Claude Code o Cursor: a partir de tu idea, el agente escribe el guion, genera cada escena con código (three.js y ffmpeg, renderizado en Chrome headless), busca material de archivo, añade motion design, efectos de sonido y música open source, y entrega un MP4. Sirve para cortos, vídeos largos de YouTube, anuncios, explicadores y videoclips. La desarrolla sarpstar (proyecto turco, con README en varios idiomas).

## Qué la distingue

- No se queda en la idea obvia: cruza tu idea con algo real elegido al azar (una pieza de museo, un animal, una foto del espacio, un invento antiguo...) para ofrecerte interpretaciones inesperadas.
- Voz sin servicio de pago: opcionalmente tu propia clave de Gemini (con cuota gratuita), ElevenLabs o una voz turca gratuita.
- Según su autor, hizo con ella un documental de 8 minutos sobre Bermuda en una noche (dejándole las decisiones al agente) y llegó al corte final con una sola revisión detallada. Experiencia del autor, no un benchmark.

## Estado

Unas 2.000 estrellas (noviembre 2026); creado el 3 de noviembre de 2026. El autor anuncia que pausa el desarrollo porque el estado actual le basta.
