# Checklist web vibecodeada (20 puntos)

Tu web vibecodeada parece terminada, pero no lo está. Lista de **Manish Kumar** ([@Manixh02](https://x.com/Manixh02)): 20 cosas que le siguen faltando a la mayoría de webs generadas con IA si quieres que sean reales y seguras.

## Los puntos visibles del hilo

- **Página 404 personalizada**
- **Meta title en cada página**
- **Meta description en cada página**
- **CTA above the fold** (llamada a la acción visible sin hacer scroll)
- **Favicon configurado**
- **Archivo robots.txt**
- **Sitemap.xml**
- **Open Graph** (previews al compartir en redes)

El hilo completo trae 20 puntos (el resto queda tras el "ver más" del post original).

## Cómo usarla con tu agente

Pégale la lista a tu agente de vibecoding como criterio de "terminado": *no está done hasta que los 20 puntos estén verificados*. Es el mismo patrón de [[AI Critic Loop]] (definir qué significa "bien" antes de iterar) aplicado a shipping web.

## Seguridad como criterio de entrega

El [OWASP Top 10](https://owasp.org/www-project-top-ten/) es un documento de concienciación sobre riesgos críticos de aplicaciones web; la versión publicada vigente consultada es 2025. No es una certificación ni una lista exhaustiva de pruebas. Complementarlo con las [OWASP Cheat Sheets](https://cheatsheetseries.owasp.org/) para prevención concreta y convertir los riesgos relevantes en pruebas de aceptación, revisión de permisos, validación de entradas y dependencias.

El [vídeo de Héctor de León](https://x.com/powerhdeleon/status/2106468531319529816), de 1:08 con voz, presenta esa base gratuita y muestra escenarios/preventivos. Que un agente genere código no demuestra que sea seguro; revisar seguridad antes de marcar terminado, no después de publicar. No se inventa la URL del curso de YouTube que el hilo menciona sin identificarla.
