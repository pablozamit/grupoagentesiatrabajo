# Kinetics

**Kinetics** es una librería open source de **135 efectos de movimiento** creada por Csaba Kissi. Cada efecto está disponible en **3 versiones: CSS, React y prompt para IA**, facilitando su uso tanto en código como en herramientas como Claude, ChatGPT o Cursor.

## Características clave

- **135 efectos de motion** listos para usar (actualizado julio 2026)
- **3 versiones por efecto**: CSS, React y prompt para IA
- **Copia como CSS** — para usar directamente en tu proyecto
- **Copia como prompt** — pegas el prompt en tu agente de IA y lo implementa
- **Open source**
- Ideal para micro-interacciones, prototipos y producción
- Nuevos efectos añadidos semanalmente
