# Kinetics

**Kinetics** es una librería open source de **99 efectos de movimiento CSS** creada por Csaba Kissi. Cada efecto se puede copiar como CSS directo o como **prompt para IA**, facilitando su uso tanto en código como en herramientas como Claude, ChatGPT o Cursor.

## Características clave

- **99 efectos de motion** listos para usar
- **Copia como CSS** — para usar directamente en tu proyecto
- **Copia como prompt** — pegas el prompt en tu agente de IA y lo implementa
- **Open source**
- Ideal para micro-interacciones, prototipos y producción
