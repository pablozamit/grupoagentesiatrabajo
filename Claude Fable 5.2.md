# Claude Fable 5.2

Claude Fable 5.2 es un modelo de Anthropic lanzado el 9 de noviembre de 2026 junto a Claude Mythos 5.2, orientado a codificación, razonamiento y visión; Anthropic lo presenta también para "diseño de 3D, hardware y motion". Se usa desde Claude Code (`--model fable`) con niveles de esfuerzo (Low, Medium, High, Xhigh, Max) y contexto de 1M de tokens. Para dirigir vídeo y motion graphics con él, ver [[Fable 5.2 Motion Playbook (flxrnc)]].
