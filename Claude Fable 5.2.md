# Claude Fable 5.2

Claude Fable 5.2 es un modelo de Anthropic lanzado el 9 de noviembre de 2026 junto a Claude Mythos 5.2, orientado a razonamiento exigente y trabajo agéntico de larga duración; Anthropic lo presenta también para "diseño de 3D, hardware y motion". Según la [documentación oficial](https://platform.claude.com/docs/en/models/fable-5-2/overview): ID `claude-fable-5-2`, contexto de 1M de tokens, salida máxima de 128K, precio de API de 8 $/MTok de entrada y 40 $/MTok de salida, thinking siempre activo y esfuerzo por defecto `high`. Se usa también desde Claude Code (`--model fable`). Para dirigir vídeo y motion graphics con él, ver [[Fable 5.2 Motion Playbook (flxrnc)]].
