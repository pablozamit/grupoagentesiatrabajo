# three.quarks

[three.quarks](https://github.com/Alchemist0823/three.quarks) es una librería open source (MIT) de sistemas de partículas y efectos visuales en tiempo real para [[Three.js]], escrita en TypeScript: renderizado por lotes optimizado para minimizar draw calls, editor visual propio, importación de sistemas de partículas Shuriken de Unity y plugins para comportamientos y emisores personalizados.
