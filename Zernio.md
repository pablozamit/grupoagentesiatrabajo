# Zernio

[zernio.com](https://zernio.com) — API unificada de redes sociales para desarrolladores y agentes de IA. Creado por un equipo de 7 personas en España, bootstrapped.

Una integración, 15+ plataformas: publicar, inbox, analíticas, anuncios y gestión de cuentas. Sin perder meses con OAuth y APIs específicas de cada plataforma.

## WhatsApp API (lanzamiento junio 2026)

Connecta un número y tienes toda la WhatsApp Business API detrás:

- Mensajería y broadcasts
- Llamadas enrutables a agentes de IA
- Chatbots y grupos
- Formularios integrados en el chat (in-chat forms)
- Números en 53 países

**Cero markup en uso:** pagas lo que cobra Meta por mensaje + suscripción mensual a Zernio.

## Para agentes de IA

Ofrece **MCP server hosted** (cero setup) además de REST, SDKs y CLI. El agente puede:

- Gestionar conversaciones con historial completo y timestamps
- Detectar ventana de 24h de WhatsApp (mensajes libres vs. templates)
- Recibir webhooks con códigos de error si un mensaje es rechazado
