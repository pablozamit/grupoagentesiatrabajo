# Cuelume

[Cuelume](https://cuelume-site.pages.dev) es un sistema de sonidos UI sintetizados que se generan en tiempo real en lugar de usar archivos MP3. Creado por [Daniel White](https://x.com/dwhitedesign).

## Características

- **2KB** de peso
- **Cero archivos** — no necesita archivos de audio externos
- **Cero dependencias**
- Sonidos táctiles sintetizados: clicks, toggles, tonos de error
- Categorías semánticas de sonido
- Se integra directamente en proyectos web

## Por qué importa

La mayoría de sonidos UI se sienten baratos porque son MP3 precargados. Cuelume genera el audio sintetizado al vuelo, lo que permite sonidos nítidos y consistentes sin peso adicional.
