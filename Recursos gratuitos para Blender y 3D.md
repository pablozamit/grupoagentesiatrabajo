# Recursos gratuitos para Blender y 3D

Catálogo de recursos para crear escenas, renders y videojuegos 3D:

| Recurso | Uso |
|---|---|
| [Poly Haven](https://polyhaven.com/) | HDRI, texturas y modelos 3D gratuitos; no requiere registro. |
| [AmbientCG](https://ambientcg.com/) | Materiales y texturas realistas. |
| [Texturelabs](https://texturelabs.org/) | Texturas para composición y renders. |
| [BlenderKit](https://www.blenderkit.com/) | Biblioteca de modelos y materiales accesible desde Blender. |
| [Mixamo](https://www.mixamo.com/) | Auto-rig y animaciones para personajes. |
| [Quaternius](https://quaternius.com/) | Modelos low-poly, especialmente útiles para prototipos y juegos. |
| [Kenney](https://kenney.nl/) | Packs de recursos 2D y 3D para videojuegos. |
| [OpenGameArt](https://opengameart.org/) | Recursos compartidos para crear juegos; revisar la licencia de cada asset. |

Antes de usar un recurso en un proyecto publicado o comercial, comprobar su licencia y las condiciones vigentes en su página.
