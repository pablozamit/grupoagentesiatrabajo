# anidoodle

[anidoodle](https://github.com/alexgreensh/anidoodle) es una skill open source (Apache-2.0) de arte dibujado a mano escrito como código: ilustraciones, timelapses de dibujo, películas, explainers y web art interactivo en 32 estilos (bolígrafo, acuarela, píxel, xilografía, sumi-e...). Cada trazo es una función, así que el mismo código redibuja la misma imagen en cualquier máquina y a cualquier tamaño; funciona en Claude Code, Codex y cualquier agente que lea skills.
