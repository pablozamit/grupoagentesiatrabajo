# Oracle Cloud Free Tier

[Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/) ofrece instancias **Always Free** sin coste, ideales para alojar herramientas de IA como [[AnythingLLM]] con Docker.

## Especificaciones

- **Arm (Ampere A1):** hasta ~4 OCPU + 24 GB RAM (la disponibilidad varía; a veces baja a 2 OCPU / 12 GB)
- **AMD pequeñas:** 2 x 1 GB
- Sin coste, siempre gratis (no trial limitado)
- Perfecto para [[AnythingLLM]] + Docker (ver [[VPS]] para más opciones)

## Usos comunes

- Alojar [[AnythingLLM]] con modelos open source
- Desplegar Docker con agentes, APIs, bases de datos
- Servidor ligero 24/7 para proyectos personales

Para más servicios con tiers gratuitos, ver [[free-for.dev]] (1.600+ servicios catalogados).
