# Cobalt

**Cobalt** ([cobalt.tools](https://cobalt.tools)) es un **descargador de medios open source** (repo `imputnet/cobalt`, AGPL-3.0, 43.1k ⭐, 3.8k forks, 56 contribuidores) que no molesta: sin anuncios, sin trackers, sin paywalls. Filosofía: *pegas el enlace, obtienes el archivo, sigues con tu día*.

## Qué hace

Descarga contenido público y gratuito (video, audio, imágenes) desde redes sociales y webs: pegas la URL y te devuelve el archivo. No guarda nada en caché — funciona como un proxy elegante. Solo sirve para contenido libre y accesible (lo mismo que podrías descargar con las devtools del navegador).

## Monorepo

El repo incluye el código de todo el servicio:

- **api** — backend de descarga y procesamiento
- **web** — frontend de cobalt.tools
- **packages** — paquetes compartidos
- **docs** — cómo correr tu propia instancia, cómo protegerla, variables de entorno y documentación de la API

Stack principal: Svelte, JavaScript y TypeScript.

## Self-hosting

Puedes correr tu propia instancia con Docker. Los docs cubren instalación, protección de la instancia y variables de entorno de la API. Parte de la infraestructura oficial la patrocina royalehosting.net.
