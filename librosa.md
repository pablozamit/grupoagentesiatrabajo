# librosa

[librosa](https://github.com/librosa/librosa) es una librería Python open source (ISC) de análisis de audio y música (MIR): detección de beat y tempo, espectrogramas y extracción de características. En un pipeline de vídeo con agentes sirve para encontrar el beat de una pista y que cada corte caiga sobre él.
