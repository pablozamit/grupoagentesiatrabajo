# Checklist Design

**Checklist Design** es una colección de checklists para revisar interfaces y flujos de producto: websites, web apps, aplicaciones móviles, componentes y design systems.

## Utilidad para agentes

- La web ofrece una **Agent Skill** y una **Figma Skill**, además de un plugin de Figma.
- Las checklists sirven como criterio de salida para que un agente revise una interfaz después de implementarla, en vez de depender solo de una valoración estética subjetiva.
- El sitio también anuncia revisiones de diseño asistidas por IA dentro del plugin de Figma.
