# Webframe

**Webframe** (`tractordev/webframe`) es un navegador headless ligero para ejecutar una página web como un programa. El bookmark de [@progrium](https://x.com/progrium/status/2114076633749676231) lo describe como una alternativa simple a un runtime de JavaScript, capaz de funcionar en distintos entornos y con un tamaño anunciado de 2 MB.

El repositorio oficial se comprobó en [GitHub](https://github.com/tractordev/webframe). La cifra de tamaño y la comparación con otros runtimes proceden del tuit, no de un benchmark independiente; conviene medir memoria, compatibilidad y protocolos antes de usarlo como navegador de agentes.

## Encaje

Puede servir como pieza de la capa de navegación de un agente cuando se priorizan arranque y consumo pequeños. Comparte espacio con [[Moli Browser]], [[Obscura]], [[Camofox Browser]] y [[Browser Use]], pero el bookmark no documenta aquí paridad con Chromium, CDP ni WebDriver.
