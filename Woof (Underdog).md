# Woof (Underdog)

Woof es un modelo de texto a voz diseñado para ejecutarse localmente dentro del navegador. Una vez descargado, puede sintetizar voz sin conexión a internet. El sistema normaliza primero textos como números de teléfono, fechas, precios y códigos, que suelen ser difíciles de pronunciar correctamente.

Se ofrecen variantes de una y dos voces. Los tamaños anunciados son 31,7 MB para una voz y 40,6 MB para dos. La comparación publicada usa 500 frases difíciles y comunica un 1,42 % de palabras erróneas para la versión de dos voces, 2,06 % para la de una voz y 1,89 % para Fish Audio Drama 3. Estas cifras describen esa prueba concreta; no permiten concluir por sí solas que la calidad sea equivalente en otros idiomas, textos o condiciones.
