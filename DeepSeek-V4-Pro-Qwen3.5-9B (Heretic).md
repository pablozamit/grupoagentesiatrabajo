# DeepSeek-V4-Pro-Qwen3.5-9B (Heretic)

Modelo local de 9.000 millones de parámetros presentado como una destilación de DeepSeek-V4-Pro sobre Qwen3.5. Se distribuye en Hugging Face con una cuantización cuyo archivo descargable ronda los 5,6 GB. La etiqueta «uncensored» indica que el ajuste busca reducir rechazos; no significa que el modelo sea infalible ni que responda bien a cualquier petición.

El tamaño del archivo no equivale a la memoria total necesaria durante la generación: también influyen la cuantización, el contexto, el runtime y el sistema operativo. Antes de elegir hardware, conviene probar el formato concreto con el runtime local que se vaya a usar.
