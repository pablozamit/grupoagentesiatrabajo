# Koboyo Icons

**Koboyo Icons** es una colección de **71.000+ iconos SVG dibujados a mano (hand-drawn) totalmente gratis** para usar sin atribución, creada con IA por **Kamran Ahmed** (el de roadmap.sh).

## Qué es

- **71.262 iconos SVG hand-drawn** con estilo consistente.
- **100% gratis** para usar como quieras. **Sin atribución requerida**.
- Esquema de color heredable: usan `currentColor` (se adaptan al texto).

## Búsqueda inteligente

- Organizados en **grupos**: face, mark, object, people, scene, solid.
- Búsqueda por **sinónimos**: escribir "oops" encuentra "facepalm", "deploy" encuentra "rocket".
- Útil para encontrar el icono exacto de estado vacío, gesto o concepto.

## Posible mejora con IA (del hilo)

Un usuario sugirió montar un **servidor MCP** para que los agentes de IA (Claude, GPT) busquen y descarguen los iconos directamente en el proyecto sin pasar por la web. Aun sin esto, el set se puede descargar/pegar en tu app o sitio.
