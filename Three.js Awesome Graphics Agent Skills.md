# Three.js Awesome Graphics Agent Skills

**Stars:** 484 ⭐ (julio 2026) — **27 skills** — [repo](https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills)

Colección de skills y ejemplos para crear **gráficos 3D avanzados** con Three.js usando agentes de IA. Mantenida por [Scott](https://x.com/scottstts). El objetivo es enseñar al agente el **vocabulario de implementaciones sofisticadas** en lugar de solo decirle "haz buenos gráficos".

## Skills incluidas

| Skill | Especialidad |
|---|---|
| threejs-skill-router | Descompone un objetivo visual en los sistemas expertos más pequeños |
| threejs-camera-direction | Lentes, planos, rigs de persecución/orbital, transiciones |
| threejs-procedural-animation | Líneas de tiempo analíticas, gravedad, spring, quaternions |
| threejs-procedural-fields | Campos escalares/vectoriales, domain warping, normales procedurales |
| threejs-procedural-materials | PBR híbrido con texturas y campos procedurales, materiales planetarios |
| threejs-parallax-occlusion-mapping | TSL height marching, siluetas recortadas, self-shadowing |
| threejs-procedural-geometry | Geometría procedural, UV density, grupos de material |
| threejs-procedural-vegetation | Ivy, grass GPU, vegetación con viento, jerarquías de crecimiento |
| threejs-procedural-architecture | Gramáticas de masas y fachadas, módulos, compilación de materiales |
| threejs-procedural-planets | Terreno esférico, crestas, cráteres, biomas, normales procedurales |
| threejs-spectral-ocean | Océano realista con FFT, Gerstner, óptica above/below, god rays |
| threejs-water-optics | Ondas analíticas, caustics, refracción, reflexión |
| threejs-precipitation-surfaces | Nieve, lluvia, acumulación, charcos, salpicaduras |

| threejs-volumetric-clouds | Nubes volumétricas con raymarching, iluminación, sombras |

| threejs-shadow-systems | Shadow cascades estables, clipmaps, presupuestos de actualización |
| threejs-screen-space-ambient-occlusion | GTAO, bent normals, reconstrucción temporal |

## Instalación

```bash
# Instalación global para cada agente
npx threejs-awesome-graphics-agent-skills@latest install --agent codex
npx threejs-awesome-graphics-agent-skills@latest install --agent claude-code

# Instalación por proyecto
npx threejs-awesome-graphics-agent-skills@latest install --agent github-copilot --scope project

# Forzar reinstalación
npx threejs-awesome-graphics-agent-skills@latest install --agent gemini-cli --force
```
