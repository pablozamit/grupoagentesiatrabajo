# Three.js Awesome Graphics Agent Skills

**Three.js Awesome Graphics Agent Skills** es una colección de skills y ejemplos para crear gráficos 3D avanzados con Three.js usando agentes de IA. Mantenida por Scott.

## Contenido (v0.5.0, julio 2026)

La librería incluye ejemplos de gráficos complejos listos para usar con agentes:

- **F1 race car** (creado con Opus 5)
- **Motorcycle** (creado con Opus 5)
- **Hologram VFX** (efecto de holograma)
- **Undersea effect** (efecto submarino del juego Pearl Sea Park)

## Instalación

```bash
npx threejs-awesome-graphics-agent-skills@latest install --agent codex
```
