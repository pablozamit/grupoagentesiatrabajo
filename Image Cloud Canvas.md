# Image Cloud Canvas

[Image Cloud Canvas](https://image-cloud-canvas-rddoptbv5-amirmushich-s-projects.vercel.app/) es una herramienta web para crear **collages visuales o moodboards** arrastrando imágenes sobre un lienzo interactivo.

- Arrastra y suelta imágenes directamente desde tu ordenador
- Muévelas con el ratón o el dedo (táctil)
- Haz zoom con la rueda del ratón
- Sirve para componer referencias visuales, hacer lluvias de ideas visuales o preparar paletas de inspiración para diseño web
- Ligera, sin registro, funciona en navegador
