# react-postprocessing

[react-postprocessing](https://github.com/pmndrs/react-postprocessing) es una librería open source (MIT) que envuelve postprocessing para react-three-fiber: la cadena de efectos de posproducción (bloom, profundidad de campo, glitch...) se declara como componentes React y la librería fusiona automáticamente los efectos en un solo pase, evitando el coste de encadenar passes tradicionales.
