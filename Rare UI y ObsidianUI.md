# Rare UI y ObsidianUI

Dos **bibliotecas open source de componentes React animados** instalables con el CLI de shadcn (un archivo por componente, el código es tuyo). Para agentes: las dos traen affordances — Rare UI incluye AGENTS.md/CLAUDE.md en su repo; ObsidianUI publica llms.txt, API docs y **servidor MCP**.

## Rare UI ([rareui.com](https://rareui.com))

- Registro shadcn ([swamimalode07/rare-ui](https://github.com/swamimalode07/rare-ui), 470 ⭐): 14–20 componentes raros (Fluid Orb, Gravity Letters, Gooey nav, Proximity Sidebar, OTP Input…)
- Todo animado con Motion y respeta `prefers-reduced-motion`

```bash
npx shadcn@latest add swamimalode07/rare-ui/fluid-orb
```

## ObsidianUI ([obsidianui.dev](https://obsidianui.dev))

- MIT ([Atharvsinh-codez/ObsidianUI](https://github.com/Atharvsinh-codez/ObsidianUI)): 30–50+ componentes (Apple Spotlight, Glass Dock, Magnetic Image Trail, Fractal Glass…) + **templates** y componente nuevo cada semana
- Developer portal con catálogo machine-readable, llms.txt y MCP: tu agente los instala sin que intervengas

```bash
npx shadcn@latest add https://obsidianui.dev/r/apple-spotlight.json
```
