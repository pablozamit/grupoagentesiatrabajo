# Warmbly

Plataforma open source de outreach por email en frío y gestión de buzones. El repositorio, con licencia Apache-2.0, incluye campañas secuenciales, inbox unificado, contactos y CRM, automatizaciones e integración con proveedores de correo. Se puede autoalojar con Docker. «Gratis para autoalojar» significa que el software no cobra licencia; siguen existiendo costes de servidor, dominios, buzones y proveedores.

No debe confundirse con una base de datos de leads como Apollo: Warmbly gestiona contactos que se importan o conectan y el envío de campañas; el repositorio no presenta una base propia de datos de prospectos como producto central.

Hay que distinguir el calentamiento local del pool alojado. En una instalación propia sin conexión a Warmbly Cloud, los buzones solo intercambian mensajes entre los buzones de esa misma instancia; la documentación del proyecto advierte que esto no es efectivo para la entregabilidad. La documentación consultada indica que Warmbly Cloud ya no acepta nuevas conexiones desde instalaciones autohospedadas. Por tanto, las promesas antiguas de conectar gratis una instalación a un pool compartido no describen necesariamente las condiciones actuales. Revisar las condiciones y precios vigentes antes de elegir la modalidad.
