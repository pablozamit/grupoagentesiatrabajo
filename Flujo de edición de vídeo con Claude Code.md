# Flujo de edición de vídeo con Claude Code

Un flujo de edición asistido por agente puede dividirse en pasos estables y revisables:

1. Cortar silencios respetando los límites de las palabras.
2. Revisar el contacto visual y las transiciones.
3. Proponer varias opciones de gancho; desarrollar un storyboard a partir de la elegida.
4. Mantener las reglas de marca —fuentes, colores, zonas seguras y estilo— en un archivo central para reutilizarlas entre vídeos.
5. Separar recursos de marca, guiones, proyecto en curso y materiales publicados en carpetas distintas.
6. Pedir aprobación antes de descargar o incorporar medios externos.
7. Entregar primero una versión ligera para revisar; renderizar la versión final de mayor resolución después de aprobarla.

Este orden separa decisiones editoriales de tareas mecánicas y evita renderizar el archivo final antes de cerrar el montaje.
