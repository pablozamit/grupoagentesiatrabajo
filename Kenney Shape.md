# Kenney Shape

**Kenney Shape** es una herramienta de escritorio que convierte **pixel art 2D en modelos 3D por extrusion**: dibujas el objeto pixel a pixel, ajustas la profundidad de cada pixel y la herramienta genera el modelo **con el UV mapping hecho de forma automatica**. Es de [Kenney Vleugels](https://x.com/KenneyNL) ([kenney.nl/tools](https://kenney.nl/tools)), creador de assets para juegos muy conocido en la escena indie.

## Que hace

- Usa arte 2D pixelado como fuente para generar assets 3D mediante **extrusion de pixeles** (cada pixel se convierte en una columna con la profundidad que le marques).
- Hace el **UV mapping solo**, sin trabajo manual.
- Exporta el asset como **modelo 3D y voxel**, o como **imagen bitmap y vectorial**.
- Los modelos salen ya **optimizados para juegos** (el autor se centra en assets game-ready), aunque se pueden pulir a mano.

## Compatibilidad

| Destino | Herramientas |
|---|---|
| Motores y suites 3D | Unity, Unreal Engine, Godot, Blender |
| Voxel | MagicaVoxel, VoxEdit, Goxel |
| Sistemas | Windows y Linux |

## Precio y estado

- Antes era una herramienta de pago; desde **octubre de 2026 es gratis para siempre** (usar y conservar).
- Fue su **ultima actualizacion**: el autor decidio liberarla y dejar de mantenerla para centrarse en otros proyectos.
- Descarga: [kenney.itch.io/kenney-shape](https://kenney.itch.io/kenney-shape).
