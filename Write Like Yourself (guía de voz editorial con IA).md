# Write Like Yourself: guía de voz editorial con IA

Una guía de voz útil se construye a partir de decisiones editoriales observables, no solo de adjetivos como «natural», «cercano» o «profesional». Reúne textos escritos por la persona, sus correcciones explícitas y el motivo de cada cambio. Los textos coescritos sirven para observar revisiones, pero no se deben tratar automáticamente como escritura propia ni como preferencias aprobadas.

La guía puede registrar ejemplos de qué conservar, qué cambiar y por qué; patrones que la persona rechaza; ritmo y longitud; diferencias entre formatos; y preguntas para revisar un borrador. Conviene enseñar también los «no»: metáforas vacías, entusiasmo genérico, simetrías repetidas, moralejas automáticas o bromas por obligación. Una frase imperfecta puede aportar intención o personalidad y merece quedarse si ya funciona. El modelo debe aprender el criterio y el contexto del ejemplo, no copiar sus frases ni repetir una broma en otros textos.

Flujo inicial: entregar dos o tres textos propios y algunas correcciones; revisar las inferencias del agente; guardar las preferencias aprobadas en un `VOICE.md`; y mantener separados el original, la edición aprobada y las propuestas pendientes. Una corrección aislada no demuestra una preferencia permanente. La guía ayuda como contexto reutilizable para redactar y revisar; no garantiza que el agente acierte ni implica entrenar o ajustar el modelo.

El repositorio incluye `START-HERE.md`, una plantilla `VOICE.template.md`, prompts para escribir, editar y revisar, ejemplos anotados y una skill opcional. Los ejemplos comparativos del propio repositorio son demostraciones preparadas en una sesión, no una evaluación controlada: no se hicieron generaciones independientes ni una puntuación ciega, y no miden una mejora objetiva.

Repositorio: [borjaperfra/write-like-yourself](https://github.com/borjaperfra/write-like-yourself). Guía de inicio: [START-HERE.md](https://github.com/borjaperfra/write-like-yourself/blob/main/START-HERE.md).
