# MiroFish

[MiroFish](https://github.com/666ghj/MiroFish) es un motor open source (AGPL-3.0) de predicción por inteligencia de enjambre: a partir de un material semilla (una noticia, un borrador de política, una señal financiera o un texto largo) construye un mundo digital paralelo donde miles de agentes con personalidad, memoria a largo plazo y lógica de comportamiento propias interactúan y evolucionan socialmente, y devuelve un informe de predicción detallado y un mundo simulado con el que se puede conversar. Funciona con GraphRAG y Zep, el motor de simulación OASIS de CAMEL-AI y cualquier LLM compatible con la API de OpenAI; se despliega en local con Node.js + Python o Docker. Incubado por Shanda Group.
