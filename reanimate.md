# reanimate

[reanimate](https://github.com/NiazMorshed2007/reanimate) es una skill open source (MIT) para Claude Code que hace ingeniería inversa de cualquier animación que veas —en una web en vivo, una grabación de pantalla, un mp4, un gif o un Lottie—: graba la referencia fotograma a fotograma, la reescribe en el código de tu proyecto (CSS, Framer Motion, GSAP o three.js) y compara la copia con el original en timing, easing y píxeles hasta que los números coinciden, normalmente en 2-5 rondas. Instalación: `npx skills add NiazMorshed2007/reanimate`; necesita Bun 1.1+ en macOS o Linux.
