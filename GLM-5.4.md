# GLM-5.4

GLM-5.4 es un modelo de IA de Z.ai con visión y generación de código, construido a partir de GLM-5 con una arquitectura Loop Transformer: recorre dos veces un bloque compartido de 28 capas para refinar sus cálculos sin aumentar el número de parámetros. Está orientado a programación y a tareas realizadas mediante código, como vídeo, juegos, 3D y diseño CAD. En el [anuncio oficial del 23 de noviembre de 2026](https://z.ai/blog/glm-5.4), Z.ai ofrece acceso mediante GLM Coding Plan, ZCode y Z.ai Chat; la API y los pesos descargables siguen pendientes de evaluación y medidas de seguridad.
