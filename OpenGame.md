# OpenGame

**OpenGame** es una herramienta de código abierto de OpenDesign para crear y adaptar videojuegos con agentes de programación como [[Codex]] y [[Claude Code]]. Integra código, recursos visuales, 3D y sonido en un flujo de trabajo local; el proyecto principal usa licencia Apache 2.0. Los modelos o servicios externos que se conecten pueden tener costes propios.
