# Readwise CLI

**Readwise CLI** es la interfaz de terminal oficial de **Readwise**: todo lo que has guardado en tu cuenta (highlights, artículos, PDFs, libros, YouTube, newsletters) queda accesible desde la línea de comandos, **para ti y para tus agentes de IA**.

## Qué permite

- **Consultar tu biblioteca desde la terminal**: buscar y recuperar highlights, artículos y documentos sin salir del shell.
- **Pensado para agentes**: como es un CLI, un agente de código puede leer tu base de conocimiento guardada y usarla como contexto (research, redacción, síntesis).
- **MCP server** (beta): alternativa a la CLI con las mismas herramientas, para conectar directamente a agentes que hablan Model Context Protocol.
- **readwise-skills**: repositorio con skills listas para usar junto a la CLI/MCP.

## Instalación

```bash
npm install -g @readwise/cli
```
