# AI Design Skills (elayadesign)

**AI Design Skills** ([github.com/elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills)) es una colección open source (MIT) de skills de diseño para herramientas de programación con IA: Claude Code, Cursor, Codex, Windsurf o cualquiera que lea un fichero de reglas en Markdown. Cada skill es una carpeta independiente. A fecha de 26-oct-2026 el repo tiene unas 7.000 estrellas y se creó el 29-jul-2026.

## Skills disponibles

| Skill | Qué hace |
|---|---|
| `landing-page-design` | Construye una landing desde cero: preguntas de entrada, estructura de página, copy de conversión y un sistema visual completo (tipografía, espaciado, radios, movimiento) |
| `design-to-motion` | Convierte un diseño estático en una demo animada exacta al píxel (de estado vacío a cargado, en bucle), exportada como MP4 para X y GIFs de 800×500 |

El autor indica que vendrán más. Una skill aparte para mejorar webs ya existentes vive en otro repo suyo.

## Cómo se instala

- **Claude Code**: clonar el repo y copiar la carpeta de la skill a `.claude/skills/`.
- **Cursor**: descargar el `SKILL.md` a `.cursor/rules/`, o pegarlo en *Rules for AI*.
- **Codex / Windsurf / Cline**: copiar el `SKILL.md` a `AGENTS.md`, `.windsurfrules` o `.clinerules`.
- **Claude.ai sin terminal**: subir el `SKILL.md` a un Project o adjuntarlo a un chat.

Los valores de diseño (fuentes, colores, espaciado, movimiento) están en una sola sección al final de cada skill: se hace un fork y se edita ahí para adaptarla a tu marca.
