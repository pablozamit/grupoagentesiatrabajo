Notas sobre gráficos 3D:

- [[Three.js]] - Librería 3D para la web
- [[Plume]] - Efectos de partículas GPU
- [[Whitespace Experiments]] - Experimentos de diseño 3D
- [[Draco]] - Compresor de modelos 3D para la web
- [[Stack 3D en web]] - Flujo completo: diseñar fuera → comprimir con Draco → renderizar con Three.js → añadir partículas con Plume
- [[Mesh3D Gallery]] - Galería curada de sitios web con gráficos 3D
- [[Blender MCP]] - Controla Blender 3D con lenguaje natural desde tu agente de IA

- [[WebGPU]] - API gráfica moderna para el navegador (compute shaders, path tracing)
- [[40 Mejores Herramientas para Vibe Coding de Juegos]] - Incluye pipelines 3D con Unreal, Unity, Meshy, Blender y Three.js
- [[Valessa]] - Visualizador 3D gratuito en navegador: SVGs a modelos 3D tipo vidrio
- [[3DSVG.Design]] - Transforma SVGs a objetos 3D animados, exportables a 4K
- [[ALON'S LIFE]] - Mundo 3D multijugador P2E en navegador con Three.js + Socket.io
- [[Depthfield]] - Convierte fotos y videos 2D en clips 3D con mapa de profundidad y cámara animada
- [[img2threejs]] - Convierte fotos a modelos procedurales Three.js (código, no meshes)
- [[Three.js Awesome Graphics Agent Skills]] - Colección de skills para gráficos 3D avanzados con agentes (F1, motos, hologramas, efectos submarinos)
