- [[Three.js]] - Librería 3D para la web

- [[Whitespace Experiments]] - Experimentos de diseño 3D
- [[Draco]] - Compresor de modelos 3D para la web

- [[Mesh3D Gallery]] - Galería curada de sitios web con gráficos 3D

- [[WebGPU]] - API gráfica moderna para el navegador (compute shaders, path tracing)
- [[40 Mejores Herramientas para Vibe Coding de Juegos]] - Incluye pipelines 3D con Unreal, Unity, Meshy, Blender y Three.js
- [[Valessa]] - Visualizador 3D gratuito en navegador: SVGs a modelos 3D tipo vidrio
- [[3DSVG.Design]] - Transforma SVGs a objetos 3D animados, exportables a 4K
- [[ALON'S LIFE]] - Mundo 3D multijugador P2E en navegador con Three.js + Socket.io
- [[Depthfield]] - Convierte fotos y videos 2D en clips 3D con mapa de profundidad y cámara animada
- [[img2threejs]] - Convierte fotos a modelos procedurales Three.js (código, no meshes)
- [[Three.js Awesome Graphics Agent Skills]] - 27 skills para gráficos 3D avanzados con agentes (F1, motos, océanos, planetas)
- [[Human Cell Visualizer]] - App 3D de biología celular con partículas, morphing y anatomía anotada (Three.js)
- [[Text-to-CAD]] - Genera archivos STEP, STL, GLB y G-code desde texto (10k ⭐)
- [[Neo-Forge]] - RTX 4090 editions interactivas (GTA VI, Matrix, Claude, Fortnite, Grok) con Three.js + img2threejs
- [[Meta TRIBE v2]] - Predice actividad cerebral desde video y la visualiza en 3D
- [[Personajes 3D jugables desde IA]] - Workflow: imagen → pose T → Trellis → rigging con Claude Opus 5 → Godot/Blender MCP
- [[BroMetal]] - Alternativa ligera a Three.js: shaders en TypeScript compilados a WGSL, solo WebGPU
- [[The Complete Shelf]] - Estantería 3D realista en Three.js con page-flip físico, de Meng To (open source + prompt)
- [[scroll-world]] - Skill que genera landing pages con camera flight continuo por el mundo 3D (scroll-scrub)
