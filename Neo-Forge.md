# Neo-Forge

**Neo-Forge** es un proyecto open source de [Amir Mušić](https://x.com/AmirMushich) que convierte **5 hojas de referencia en ediciones interactivas RTX 4090**: GTA VI, Matrix, Claude, Fortnite y Grok. Construido con **Three.js + img2threejs**.

**Repo:** [github.com/amirmushichge/neo-forge](https://github.com/amirmushichge/neo-forge)

## Qué hace

- Toma imágenes 2D de referencia (hojas de estilo, wallpapers, concept art) y las convierte en modelos 3D interactivos de tarjetas RTX 4090
- Cada edición tiene una estética distinta según la temática (GTA VI, Matrix, Claude AI, Fortnite, Grok)
- Los modelos son editables y se pueden **retexturizar** con Codex + Nano Banana o GPT Image v2 (ej. poner tu logo en la RTX)

## Tecnología

- **Three.js** para renderizado 3D en navegador
- **img2threejs** para convertir imágenes 2D en geometría procedural
- **Codex** + modelos de imagen (Nano Banana, GPT Image v2) para retexturizado

## Por qué importa

Demuestra el pipeline completo de img2threejs aplicado a un caso real: referencia 2D → código Three.js procedural → modelo 3D interactivo → retexturizado con IA. Es un ejemplo práctico de "reconstruir, luego editar" en 3D.
