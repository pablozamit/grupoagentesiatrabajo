# RapidAPI

**RapidAPI** ([rapidapi.com](https://rapidapi.com/)) es el mayor marketplace de APIs: permite buscar, probar y consumir miles de APIs con una sola cuenta y una sola key.

## Puntos clave

- Hay varias APIs de scraping de Google Maps publicadas en el hub: opción rápida cuando no quieres montar scraper propio ni pagar una herramienta dedicada.
- Modelo típico: capa gratuita limitada + pago por uso.
