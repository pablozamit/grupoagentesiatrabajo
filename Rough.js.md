# Rough.js

[Rough.js](https://github.com/rough-stuff/rough) es una librería JavaScript open source (MIT) que genera gráficos con apariencia dibujada a mano: líneas, formas y rellenos con el trazo irregular de un boceto. Sirve para dar a interfaces y diagramas un estilo sketch sin dibujar nada a mano.
