# motion-design-skill

[motion-design-skill](https://github.com/LottieFiles/motion-design-skill) es una skill open source (MIT) de LottieFiles con principios universales de motion design para agentes: timing, easing, coreografía e intención emocional antes de escribir código, agnóstica de implementación (CSS, Framer Motion, GSAP, Lottie, Spring). Incluye un checklist de 8 pasos, arquetipos de personalidad de movimiento y los 12 principios Disney adaptados a UI; para exportar a MP4, GIF o Lottie se combina con el Creator MCP de LottieFiles.
