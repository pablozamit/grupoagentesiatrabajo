# huashu-motion

[huashu-motion](https://github.com/alchaincyf/huashu-motion) es una herramienta open source (MIT) para que un agente de código produzca vídeos de lanzamiento de producto de nivel comercial de una vez: compone la música para el vídeo y permite señalar un fotograma concreto para pedir cambios sobre él.
