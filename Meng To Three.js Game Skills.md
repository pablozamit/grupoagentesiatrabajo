# Meng To Three.js Game Skills

**Meng To** (fundador de Design Code) ha open-sourceado sus skills de desarrollo de juegos con Three.js. Incluyen todo lo necesario para crear un RPG isométrico de acción completo.

## Contenido

- Controles de cámara
- VFX (efectos visuales)
- Audio
- Assets de monstruos
- Sistemas de combate
- Inventario completo
- Skill de rendimiento para optimización

## Juego de ejemplo: Vesperfall

Un RPG isométrico inspirado en Dark Souls y Diablo, construido con estas skills:
- [Jugar Vesperfall](https://vesperfall.mengto.chatgpt.site)
- [Catálogo de assets](https://vesperfall.mengto.chatgpt.site/asset-catalog)

## Flujo de trabajo recomendado (según Meng To)

1. Empezar con referencias fuertes del juego (screenshots, monstruos, iconos)
2. Pedir al agente que genere nuevas imágenes inspiradas en esas referencias
3. Usar [[img2threejs]] para crear assets 3D con el skill `build-game-monster-system`
4. Incluir skill de rendimiento: gráficos configurables, low-poly, texturas, chequeo de performance regular

## Tiempo de desarrollo

- Primera versión jugable: 24 horas
- Versión completa con inventario, combate, etc.: ~3 días
