# Shannon

Pentester agéntico de código abierto para aplicaciones web y APIs. Shannon analiza el código fuente para proponer rutas de ataque y ejecuta pruebas activas contra una aplicación desplegada para intentar demostrar vulnerabilidades mediante exploits. En las integraciones oficiales de CI, analiza el repositorio y ataca el entorno de desarrollo o staging; guarda informes PDF, Markdown y SARIF, además de logs para revisar ejecuciones incompletas.

No es un escáner pasivo: sus agentes pueden crear usuarios, enviar formularios, cambiar estado de la aplicación y generar peticiones salientes. Hay que usarlo solo contra sistemas propios o con autorización expresa, preferiblemente en staging con datos desechables. Un hallazgo requiere revisión humana y un resultado sin exploits no demuestra que la aplicación sea segura. El proyecto comunitario está bajo AGPL-3.0; las versiones comerciales añaden capacidades y servicios gestionados distintos.
