# Remotion

[Remotion](https://github.com/remotion-dev/remotion) es un framework para crear vídeos programáticamente con React: cada fotograma se renderiza desde código y se exporta a MP4. Al ser el vídeo un programa, un agente puede construirlo, medirlo y corregirlo fotograma a fotograma; es el motor del flujo documentado en [[El vídeo es código]] y del kit [[launch-video-kit]]. El proyecto mantiene skills oficiales para agentes ([remotion-dev/skills](https://github.com/remotion-dev/skills)).
