# OpenShip

**OpenShip** es una plataforma open source para construir, desplegar y escalar aplicaciones en tu propia infraestructura. Reemplaza herramientas de deployment, servicios gestionados y flujos de infraestructura con una sola plataforma auto-hospedada.

## Características

### Mail Server (integrado, un clic)
- Correo en tu propio VPS
- Dominios ilimitados
- Buzones ilimitados
- Webmail moderno incluido
- Conectable con Gmail, Outlook, Apple Mail o cualquier IMAP/SMTP
- Sin tarifas por buzón ni API fees
- Alta deliverabilidad

### Deployment
- Cualquier stack
- Deployments por git
- Zero-downtime
- Rollbacks con un clic
- Entornos Development, Staging y Production
- Multi-branch con entornos aislados

### Servicios integrados (un clic)
- Supabase
- PostgreSQL
- MySQL / MariaDB
- MongoDB
- Redis
- MinIO
- Meilisearch
- Qdrant
- RabbitMQ
- Kafka
- ClickHouse
- Elasticsearch

### Operaciones
- Logs en vivo de deployments y requests
- Analíticas de tráfico en tiempo real
- Backups automáticos
- Monitorización
- Gestión de secretos
- SSL automático
- Health checks
- Tareas programadas

### Seguridad y equipos
- Roles y permisos (RBAC)
- Reglas IP allow/block
- Rate limiting
- Gestión de equipos

### Developer Experience
- Web dashboard
- App de escritorio nativa
- CLI
- REST API
- **MCP support** para agentes de IA

### Próximamente
- Clustering multi-servidor
- Load balancing con un clic
- Escalado horizontal
- Alta disponibilidad y failover
