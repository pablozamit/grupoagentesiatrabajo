# Crawl4AI

**Crawl4AI** es un **crawler web open source** (51k ⭐ según el hilo viral de @taozi0929, 169k views) pensado para alimentar a los LLMs: le pasas cualquier URL y devuelve **Markdown limpio listo para que un modelo lo devore**. Nació porque su autor se cansó de pagar 16 $/mes a un servicio de crawling de pago y publicó el suyo propio.

## Por qué importa

- **Sin API key, sin registro, sin pago por página**: corre en tu máquina
- Según el hilo, corre **más rápido** que varios servicios de pago que los usuarios habían probado
- La tesis del post: las barreras del crawling web cayeron hace años — cobrar suscripción mensual por esto es puro margen

## Casos de uso típicos

- Convertir páginas de Wikipedia y docs a Markdown limpio de un plumazo
- Alimentar a tu agente con contenido web sin pelearte con HTML sucio ni JS
- Construir datasets a partir de webs públicas
