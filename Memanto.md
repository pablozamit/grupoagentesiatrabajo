# Memanto

[Memanto](https://github.com/moorcheh-ai/memanto) es una **capa de memoria universal open source** para agentes de IA. Permite que tus agentes recuerden contexto entre sesiones sin que tengas que repetírselo una y otra vez.

## Qué es

- Capa de memoria persistente para agentes de código y chat con IA
- Open source (licencia MIT) y **gratis para empezar**
- Guarda el contexto de tus sesiones de trabajo
- Lo comprime y organiza con IA
- Recupera lo relevante en **menos de 90 ms**
- **Sin bases de datos vectoriales** y sin configuración compleja

## El problema que resuelve

Los modelos de IA olvidan el contexto entre sesiones. Si trabajas con un agente en un proyecto, cada vez que abres una conversación nueva tienes que volver a explicarle de qué va el proyecto, qué decisiones tomaste, qué archivos tocar, etc. Eso consume tiempo y tokens.

Memanto añade una capa de memoria persistente: tu agente **simplemente recuerda** lo que aprendió en sesiones anteriores.

## Instalación

Un solo comando:

```bash
pip install memanto
```

Sin servidor local, sin Docker, sin YAML.

## Herramientas compatibles

Funciona con una larga lista de agentes y entornos:

- **Claude Code**
- **Codex (CLI)**
- **Cursor**
- **Windsurf**
- **Antigravity**
- **Gemini CLI**
- **Cline**
- **Continue**
- **OpenCode**
- **Goose**
- **Roo**
- **GitHub Copilot**
- **Augment**

Se conecta con `memanto connect <herramienta>` (local o global).

## Características principales

- **Recall semántico persistente** entre sesiones
- Recuperación **sub-90 ms** en producción
- CLI potente integrada — gestiona las memorias de tu agente desde el terminal
- Modo de memoria agentic
- RAG integrado con selección de modelo
- Modo IA directo (proxy de LLM drop-in)
- Auto-hospedable cuando lo necesites

## Modelo de uso

- Plan gratuito: **500 Compute Units gratis** (unas 100.000 operaciones), sin tarjeta
- Almacenamiento de memorias: **siempre gratis**
- Retención ilimitada
- Hasta 5 agentes
- Open source y auto-hospedable

## MemantoClaw

Versión con memoria integrada de larga duración para **NemoClaw**: trae las capacidades de Memanto a flujos agentic nativos, con recuperación semántica entre sesiones, ingestión sin coste extra y soporte para llamadas agentic.
