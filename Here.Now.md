# Here.Now

[Here.Now](https://here.now) es un **servicio de hosting web gratuito e instantáneo** diseñado para agentes de IA. No requiere cuenta.

## Qué es

- Hosting gratis y sin registro
- Diseñado para que un agente de IA publique contenido al instante
- Tu web queda online en `tu-url.here.now`

## Cómo usarlo con un agente

Dile a tu agente algo como: *"Publica esto en www.here.now"*

El agente puede instalar la skill si tiene npm:

```
npx skills add heredotnow/skill --skill here-now -g
```

O instalarlo manualmente:

```
curl -fsSL https://here.now/install.sh | bash
```

Sin cuentas, sin tarjetas, sin esperas.
