# VPS

Un **VPS (Servidor Privado Virtual)** es un servidor en la nube que funciona 24/7 y puedes alquilar por poco dinero. Permite alojar aplicaciones, agentes, APIs o bases de datos accesibles desde cualquier lugar.

## Opciones gratuitas / económicas

- [[Oracle Cloud Free Tier]] — VPS gratis Always Free con hasta 4 OCPU + 24 GB RAM
- [[free-for.dev]] — Lista de 1.600+ servicios con tiers gratuitos, incluye más opciones de VPS/IaaS
- Proveedores de pago: DigitalOcean, Hetzner, Linode, Vultr (desde ~$4/mes)

## Usos comunes

- Alojar [[AnythingLLM]] con Docker
- Desplegar agentes de IA 24/7
- APIs, bases de datos, web scraping automatizado
- Entornos de desarrollo remotos
- Montar tu propia VPN: [[VPN privada con VPS (3x-ui + VLESS REALITY)]]
